# BOM选型评审及交付风险预警系统

V5版本首版开发工程，采用 Streamlit + Python + SQLite。

## 安装依赖

```bash
pip install -r requirements.txt
```

## 启动系统

```bash
streamlit run app.py
```

启动后，数据库 `data/app.db` 会自动初始化。如果删除该文件后重新启动，系统会自动重新创建数据库和默认规则。

## 运行测试

```bash
pytest
```

## 样例数据使用流程

系统已在 `data/samples/` 下预置样例数据：

- `sample_bom.xlsx` — BOM 样例
- `sample_supply.xlsx` — 供应风险数据样例

完整使用流程：

1. 启动应用后，在侧边栏选择 **BOM导入**，上传 `sample_bom.xlsx`，点击"保存导入结果"。
2. 在侧边栏选择 **供应数据导入**，上传 `sample_supply.xlsx`，点击"保存供应数据"。
3. 在侧边栏选择 **风险评分**，选择已导入的 BOM 批次，点击"开始评分"。
4. 评分完成后，可查看风险汇总和评分明细，点击"导出评审报告"生成 Excel 报告。
5. 在侧边栏选择 **首页** 查看最近导入和评分概览，或选择 **历史记录** 查看已评分批次。

## 常见问题

**Q：上传非 Excel 文件会怎样？**  
A：页面会提示"BOM文件读取失败"或"供应数据文件读取失败"，并在操作日志中记录失败。

**Q：BOM 中有物料找不到供应数据会怎样？**  
A：评分结果中该物料会被标记为"高风险"，风险原因为"未找到供应风险数据"，并在评分页面单独展示。

**Q：历史价格为 0 或为空时价格涨幅怎么算？**  
A：系统不会崩溃，会在风险原因中提示"无法计算价格涨幅"。

**Q：修改规则后已有评分结果会变化吗？**  
A：不会自动变化。需要重新选择批次并点击"开始评分"，才会使用新规则生成新结果。
