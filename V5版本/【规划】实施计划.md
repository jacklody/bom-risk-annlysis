# 实施计划：BOM选型评审及交付风险预警系统

创建日期：2026-07-10

## 项目实施原则

首版系统采用 Streamlit + Python + SQLite 的单体应用方案。本计划只覆盖一周内可完成的MVP范围：BOM导入、供应风险数据导入、自动风险评分、结果查看、报告导出和操作日志。

以下内容不进入首版开发范围：ERP/PLM实时对接、审批流、复杂权限、实时通知、多层BOM展开、AI预测模型。涉及替代料、共用料、虚拟件和版本差异的字段会在首版保留，但只作为单层BOM评分依据。

## 步骤 1：项目初始化与运行骨架

- **描述**：创建项目目录、Python虚拟环境、依赖文件和最小Streamlit页面。该步骤的目标是先让应用能在本地启动。

    - [ ] 创建项目目录 `bom-risk-review`。
    - [ ] 创建 `requirements.txt`，至少包含 `streamlit`、`pandas`、`openpyxl`、`plotly`、`pytest`。
    - [ ] 创建 `app.py`，显示项目标题“BOM选型评审及交付风险预警系统”。
    - [ ] 创建 `src/`、`data/`、`data/samples/`、`data/exports/`、`tests/` 目录。
    - [ ] 创建 `.gitignore`，排除虚拟环境、缓存文件、数据库文件和导出文件。
- **验收标准**：
    - 在项目根目录执行 `pip install -r requirements.txt` 能成功安装依赖。
    - 执行 `streamlit run app.py` 后，浏览器能打开系统首页。
    - 首页能看到系统标题和“项目初始化完成”的提示文本。
    - 项目目录中存在 `src/`、`data/samples/`、`data/exports/`、`tests/`。
- **依赖性**：无

## 步骤 2：Excel模板与样例数据

- **任务**：

    - [ ] 定义供应风险模板字段：`物料编码`、`供应商数量`、`主供应商`、`标准交期`、`当前库存`、`库存变化率`、`当前价格`、`历史价格`、`是否停产`、`是否有替代料`。
    - [ ] 在 `data/samples/` 下生成 `sample_bom.xlsx` 和 `sample_supply.xlsx`。
    - [ ] 样例数据至少包含8条物料，其中包含推荐使用、谨慎使用、不推荐使用三类场景。
- **验收标准**：
    - `sample_bom.xlsx` 能被Excel正常打开。

    - [ ] 创建 `import_batches` 表，记录导入批次。
    - [ ] 创建 `bom_items` 表，保存BOM明细。
    - [ ] 创建 `supply_risk_data` 表，保存供应风险数据。
    - [ ] 创建 `risk_results` 表，保存评分结果。
    - [ ] 创建 `risk_rules` 表，保存规则阈值。
    - [ ] 创建 `audit_logs` 表，保存操作日志。
    - [ ] 首次启动应用时自动创建 `data/app.db`。
- **验收标准**：
    - 删除 `data/app.db` 后执行 `streamlit run app.py`，系统能自动重新创建数据库。

## 步骤 6：风险规则引擎

- **描述**：实现物料级风险评分逻辑，输出风险等级、推荐结论、风险原因和建议动作。该模块应独立于页面，便于测试。
- **任务**：
    - [ ] 创建 `src/risk_engine.py`。
    - [ ] 实现BOM数据与供应风险数据按 `物料编码` 匹配。
    - [ ] 实现高风险规则：停产、单一来源且无替代料、交期超过60天。
    - [ ] 实现中风险规则：交期超过30天且不超过60天、价格涨幅超过20%、库存下降率超过30%、无替代料。
    - [ ] 输出字段：`物料编码`、`物料名称`、`风险等级`、`推荐结论`、`风险原因`、`建议动作`。
    - [ ] 为 `risk_engine.py` 编写单元测试。
- **验收标准**：
    - 执行 `pytest tests/test_risk_engine.py` 能全部通过。
    - 停产物料的风险等级为 `高`，推荐结论为 `不推荐使用`。
    - 单一来源且无替代料的物料风险等级为 `高`，风险原因包含“单一来源”和“无替代料”。
    - 交期45天的物料风险等级为 `中`，推荐结论为 `谨慎使用`。
    - 无任何风险命中的物料风险等级为 `低`，推荐结论为 `推荐使用`。
    - 每条评分结果至少包含一条可读的风险原因；低风险物料可显示“未命中风险规则”。
- **依赖性**：步骤 3、步骤 4、步骤 5

## 首版完成定义

系统达到以下状态即可认为MVP完成：

- 本地可以通过 `streamlit run app.py` 启动。
- 可以导入BOM Excel和供应风险Excel。
- 可以根据规则生成物料级风险等级、推荐结论、风险原因和建议动作。
- 可以在页面查看高/中/低风险统计和明细。
- 可以导出Excel评审报告。
