# v3.2 完整可演示闭环实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 BOM Risk Analyzer v3.2 从“能展示前端字段”推进到“可用样例 BOM 跑通完整演示闭环”。

**Architecture:** 不改变现有业务 API，新增一个样例 BOM、一个 pytest 级演示闭环测试、一个 PowerShell 演示启动脚本和说明文档。演示闭环使用 FastAPI TestClient 验证上传、分析、人工事件录入、重新分析和 v3.2 依据链输出，避免依赖公网实时供应链 API 的不稳定性。

**Tech Stack:** FastAPI TestClient、pytest、CSV 样例 BOM、PowerShell、Vue/Vite 现有前端。

## Global Constraints

- 不新增 Python 或前端依赖。
- 不绕过现有接口，必须使用 `/api/bom/upload`、`/api/risk/analyze/{upload_id}`、`/api/events/manual`。
- 样例 BOM 必须覆盖高容 MLCC、MCU、电源 IC、连接器等典型物料。
- 演示闭环必须校验 v3.2 字段：`v32_category`、`v32_risk_level`、`v32_primary_track`、`v32_evidence_chain`、`v32_action_suggestion`。
- 启动说明必须明确前端地址、后端地址、常见端口问题和手动验证路径。
