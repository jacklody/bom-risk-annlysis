# BOM 交期风险排查 v0.3.0

## 版本说明

v0.3.0 是在 v0.2.0 基础上进行的前端架构整改版本。核心目标：
- **消除功能重复**：合并分散在 4 个页面的情报相关模块
- **清晰涨价影响链路**：新增从原始情报 → 信号 → 事件 → BOM 影响的可视化溯源
- **精简仪表盘**：去掉通知噪音，聚焦风险数据

## 主要变更

### 1. 新增：行情情报中心 (`IntelligenceCenter.vue`)

将原先分散的 4 个页面合并为统一的 4 Tab 页面：

| Tab | 原页面 | 职责 |
|-----|--------|------|
| 情报录入 | MarketInbox + 手动转发 | 提交原始通知、信号抽取、待复核队列管理 |
| 事件库 | MarketEvents | 查看/筛选/管理市场事件（统一事实中心） |
| 趋势预警 | MarketTrends | 趋势分布、主动预警行动队列、预测验证 |
| 采集监控 | IntelWatch | 关注指令、媒体源状态、采集运行记录 |

**边界清晰**：
- 情报录入 = 原始信息入口
- 事件库 = 结构化事实中心
- 趋势预警 = 聚合分析和行动建议
- 采集监控 = 采集配置和运行状态

### 2. 新增：涨价影响链路组件 (`ImpactChain.vue`)

可视化展示 5 步完整链路：
1. **原始情报** → 来源类型/名称/摘要/原始链接
2. **信号抽取** → 品牌/品类/型号/置信度/复核状态
3. **市场事件** → 事件类型/严重度/涨价幅度/交期影响
4. **BOM匹配** → 受影响项目数/物料数/风险分布
5. **处置建议** → 紧急行动/关注事项

### 3. 改进：事件详情抽屉 (`MarketEventDetailDrawer.vue`)

- 将 ImpactChain 集成到详情抽屉顶部，作为最重要的信息首先展示
- 重新组织信息结构：基本信息 → 触发条件 → 信息来源 → 影响范围
- 触发条件使用卡片式展示（严重度/置信度/交期/价格）
- 影响范围使用数据卡片 + 项目列表

### 4. 精简：风险仪表盘 (`RiskDashboard.vue`)

移除的内容：
- 通知预览、通知通道、通知执行历史（非仪表盘核心功能）
- 趋势行动摘要（已合并到情报中心-趋势预警 Tab）

保留的核心内容：
- 总览卡片（项目总数/高风险/红色物料/活跃事件/待处理行动）
- 项目风险表 + 品类风险表
- 风险变化摘要 + 近期活跃事件
- 供应源状态

### 5. 路由简化

| 旧路由 | 新路由 |
|--------|--------|
| `/events` | `/intelligence?tab=events` (重定向) |
| `/market-trends` | `/intelligence?tab=trends` (重定向) |
| `/market-inbox` | `/intelligence?tab=intake` (重定向) |
| `/watch` | `/intelligence?tab=monitor` (重定向) |

旧路由保留并自动重定向到新路由，确保已有的链接和跳转不会断裂。

### 6. 侧边栏

侧边栏布局保持不变，但：
- 原 4 个菜单项（市场事件/行情收件箱/趋势预警/情报监控）合并为 1 个「行情情报中心」
- 高亮标识，突出这是核心操作入口

## 与原版本的关系

- 后端 API 不变，完全兼容
- 所有原页面保留在仓库中（`已分类整理/09_开发工程源码与测试/BOM-Risk-Analyzer-patch/frontend/`）
- `frontend-v2` 是独立副本，不影响原版本

## 启动方式

```bash
cd frontend-v2
npm install
npm run dev
# 访问 http://127.0.0.1:9001
# 确保后端在 http://127.0.0.1:8001 运行
```
