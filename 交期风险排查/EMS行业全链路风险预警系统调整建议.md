# EMS行业全链路风险预警系统调整建议

## 核心判断

现有系统的方向需要从“展示材料行情和BOM风险结果”升级为“EMS行业全链路风险响应系统”。用户真正需要的不是单点材料涨跌，而是通过风险信号判断趋势，再把趋势反馈到两个业务场景：

1. **新项目BOM选型评审**：判断某个器件、品牌、工艺、封装、材料路线是否会在未来价格、交期、合规和替代性上形成隐患。
2. **老项目交付风险把控**：判断当前在产项目是否会受到上游行情、供应商事件、自然灾害、政策变化、物流波动、原厂生命周期变化的影响，并自动提升风险等级。

因此，“风险链路驾驶舱”中间部分不应只是孤立展示几条材料链路，而应该变成一个可追溯的链路图谱：

```text
外部风险信号
→ 产业链节点
→ 上游基础材料 / 制程 / 产能 / 区域
→ BOM元器件类别
→ BOM具体型号 / 品牌 / 供应商
→ 新项目选型结论 / 老项目交付风险 / 策略建议
```

系统不要求未卜先知，但要做到**第一时间捕捉风险信号、判断影响范围、自动提升风险等级、给出可解释的BOM级反馈**。

## 现有系统需要调整的关键问题

### 风险链路驾驶舱中间层关联不够

当前驾驶舱中间的“上游材料链路”更多是静态示例，还没有与 BOM 中的元器件类型、项目用量、供应商、替代难度、交付时间窗口形成强关联。正确的逻辑应该是：

```text
铜价上涨
→ 铜箔 / 铜杆 / 铜合金 / 漆包线 / 引线框架 成本上升
→ PCB / 连接器 / 线束 / 电机 / 继电器 / 电感 / 变压器 / 功率器件 受影响
→ 命中BOM中具体型号
→ 判断价格风险、交期风险、替代风险、项目交付风险
```

也就是说，一个行情事件不能只停留在“铜价上涨”，而要自动向下传导到所有关联 BOM 行。

### 风险等级不能只由价格涨跌决定

材料价格没有明显上涨，并不代表风险正常。EMS行业里，很多风险不是先体现在价格上，而是先体现在：

- 原厂涨价函
- PCN / EOL / LTB
- 分销库存下降
- 交期拉长
- 出口管制
- 关税排除到期
- 产区地震 / 台风 / 洪水 / 火灾
- 港口拥堵 / 航线中断
- 上游矿山、冶炼厂、晶圆厂、封测厂事故
- 单一品牌或单一供应商依赖

因此，系统应把“正常”改成更严谨的状态体系：

| 状态 | 含义 | 系统行为 |
|---|---|---|
| 红色 | 已经影响BOM交付或成本 | 推送预警，要求采购/研发/项目处理 |
| 橙色 | 高概率影响价格或交期 | 自动提升关注等级，输出替代和锁价建议 |
| 黄色 | 出现早期风险信号 | 纳入观察池，持续跟踪趋势 |
| 绿色 | 有利采购窗口或风险下降 | 提醒择机备货或谈价 |
| 灰色 | 数据不足 / 未接入 / 待人工确认 | 不能显示为正常，应提示补数或人工判断 |

### 数据源覆盖太窄会限制及时性

只接上海有色网、我的钢铁网、公众号和少量API，会导致预警能力不足。上海有色网覆盖铜、铝、铅、锌、锡、镍、锂电、稀土、半导体、不锈钢等大宗和产业链栏目；我的钢铁网覆盖钢材、有色、铁矿石、不锈钢、钢厂检修、库存、国际钢市等信息。这些是重要来源，但不能覆盖完整EMS风险。系统还需要接入交易所、行业协会、政府监管、自然灾害、天气、物流、原厂公告、分销库存、海关/关税/限制清单等来源。

## EMS全链路风险体系建议

### 一级链路：宏观和政策风险

这一层决定供应链环境是否发生结构性变化。

| 风险类型 | 典型信号 | 影响对象 | 建议数据源 |
|---|---|---|---|
| 出口管制 | BIS新规、实体清单、先进计算限制 | AI芯片、GPU、FPGA、高端MCU、EDA、设备 | BIS、Federal Register、Trade.gov CSL |
| 关税变化 | 301关税、232调查、豁免到期 | 出口美国项目、金属、半导体、机械件 | USTR、CBP、Federal Register |
| 地缘冲突 | 制裁、航线中断、关键矿产限制 | 半导体、连接器、电池、磁材、贵金属 | 政府公告、国际组织、主流新闻源 |
| 汇率和利率 | 人民币、美元、日元、欧元波动 | 进口器件、海外原厂报价 | 央行、外汇交易中心、银行接口 |
| 环保和能耗 | 限电、环保检查、产能压降 | PCB、电镀、钢材、铝、化工、树脂 | 政府公告、行业协会、地方通知 |

BIS官网明确承担技术领先和出口管制职责，适合做出口管制风险的一级来源；USTR提供中国301关税行动和排除程序页面，适合跟踪关税排除和税率变化；Trade.gov的Consolidated Screening List可用于供应商和客户限制名单筛查。[1][2][3]

### 二级链路：自然灾害和区域中断风险

EMS供应链对区域灾害非常敏感。一个地震、台风、洪水或火灾，可能影响晶圆厂、封测厂、PCB厂、电镀厂、港口、机场、仓库和关键供应商园区。

| 风险类型 | 影响路径 | 建议数据源 |
|---|---|---|
| 地震 | 晶圆厂停线、精密设备校准、物流中断 | USGS实时地震、GDACS |
| 台风 / 飓风 | 港口关闭、空运延误、沿海工厂停工 | GDACS、NOAA、国家气象机构 |
| 洪水 | 工业园停工、仓库受损、陆运中断 | GDACS、气象API、地方应急公告 |
| 火灾 | 化工厂、PCB厂、电池厂、仓库中断 | GDACS、新闻源、地方消防公告 |
| 干旱 / 高温 | 限电、用水限制、航运水位下降 | GDACS、气象API、电力公告 |

USGS提供全球实时地震通知、feed和web services；GDACS覆盖地震、热带气旋、洪水、火山、干旱、森林火灾等灾害事件；NOAA National Weather Service API提供天气预警、预报和观测数据。这些源应作为系统自动事件监测的重要基础。[4][5][6]

### 三级链路：半导体和电子产业链风险

半导体风险不能只看某颗芯片库存，要从晶圆、制程、封测、载板、引线框架、电子气体、光刻胶、硅片、先进封装、原厂生命周期共同判断。

| 产业节点 | 上游因子 | 下游影响 |
|---|---|---|
| 晶圆厂 | 晶圆产能、设备、光刻胶、电子气体、硅片 | MCU、PMIC、模拟IC、功率器件、存储 |
| 封测厂 | 封装基板、引线框架、金线/铜线、环氧塑封料 | QFN、BGA、SOP、TO封装交期 |
| 功率半导体 | SiC/GaN衬底、外延、封装陶瓷、铜夹 | 电源、逆变器、工业控制 |
| 存储 | DRAM/NAND周期、先进制程产能 | 模块、嵌入式存储、消费电子 |
| 原厂生命周期 | PCN、EOL、LTB、车规认证变化 | 老项目交付和替代风险 |

SEMI的市场数据覆盖晶圆厂预测、硅片、半导体材料、封装、设备等模块，并提到其数据收集项目覆盖硅、polysilicon、leadframes、electronic gases、photoresist等项目，适合作为半导体上游链路建模参考。[7]

### 四级链路：EMS核心物料类别到基础材料

系统应建立“BOM元器件类型 → 材料组成 → 行情源 → 风险传导”的知识图谱。

| BOM类别 | 上游材料/制程 | 主要行情和事件源 | 典型风险传导 |
|---|---|---|---|
| PCB / FPC | 铜箔、CCL、玻纤布、环氧树脂、PI膜、油墨、电镀铜 | SMM、LME、SHFE、树脂/玻纤行业数据、IPC | 铜价/树脂上涨 → PCB报价上涨；环保/限电影响电镀产能 |
| MLCC | 钛酸钡、镍粉、铜端头、银浆、陶瓷粉体 | SMM镍/银、稀土、陶瓷粉体、原厂公告 | 镍/银波动 + 高容需求 → MLCC价格和交期风险 |
| 铝电解电容 | 铝箔、电解液、纸、橡胶塞 | SMM铝、化工、电解液 | 铝价/电解液上涨 → 电容成本上行 |
| 薄膜电容 | PP/PET薄膜、铝/锌喷金、环氧树脂 | 化工、SMM铝/锌、薄膜行业数据 | 薄膜供给收紧 → 交期拉长 |
| 电阻 | 陶瓷基板、镍铬膜、钌浆、铜端头 | 贵金属、陶瓷、SMM镍/铜 | 贵金属/陶瓷基材波动 → 精密电阻风险 |
| 连接器 | 铜合金、镀金/锡/镍、LCP/PBT/PA66、冲压电镀 | SMM铜/锡/镍/金、工程塑料、电镀政策 | 金属+塑胶+电镀共同驱动价格和交期 |
| 线束 | 铜线、PVC/XLPE/TPE、端子、护套 | SMM铜、塑料、阻燃剂 | 铜价上涨 → 线束成本上升 |
| 继电器 | 银触点、铜线圈、铁镍合金、塑胶壳 | SMM银/铜/镍、Mysteel钢材、塑胶 | 银触点和铜线圈成本影响继电器 |
| 电感 / 变压器 | 铜线、磁芯、铁氧体、硅钢片、骨架 | SMM铜、Mysteel硅钢、稀土/铁氧体 | 铜和磁材波动 → 磁性件价格/交期风险 |
| MOSFET / IGBT | 晶圆、铜框架、环氧塑封料、陶瓷/DBC | SEMI、SMM铜、封装材料、原厂公告 | 晶圆+封装产能 → 功率器件交期风险 |
| 散热器 | 铝型材、压铸铝、铜热管、导热硅胶 | SMM铝/铜、Mysteel铝加工/钢材、化工 | 铝价和加工费影响结构散热件 |
| 结构件 | 冷轧板、不锈钢、铝板、锌合金、ABS/PC/PA | Mysteel、SMM、塑料行情 | 钢/铝/塑料波动 → 结构件报价变化 |
| 电池 | 碳酸锂、钴、镍、锰、石墨、铜箔、铝箔 | SMM锂电、USGS、交易所 | 锂钴镍波动 → 电池成本和供应风险 |
| 显示/光电 | 玻璃基板、偏光片、LED芯片、稀土荧光粉 | 面板行业数据、稀土、半导体 | 面板周期和稀土材料影响供应 |

LME铜页面说明铜是电气系统、建筑、电动车和可再生能源的重要金属，且LME官方价是全球铜基准价；SHFE页面提供铜、铝、镍、锡等期货行情；SMM页面覆盖铜、铝、铅、锌、锡、镍、锂电、稀土、半导体、不锈钢等栏目；Mysteel页面覆盖钢材、有色、铁矿石、不锈钢、钢厂检修、库存和国际钢市等信息。这些源可共同作为材料行情层的基础来源。[8][9][10][11]

### 五级链路：物流、库存和供应商风险

行情只解决“成本趋势”，但EMS交付风险还必须看库存、产能、运输和供应商状态。

| 风险类型 | 触发信号 | 对系统的要求 |
|---|---|---|
| 分销库存下降 | DigiKey/Mouser/LCSC库存减少，价格阶梯上升 | 自动提升对应型号和替代料风险 |
| 原厂交期拉长 | 交期从8周变16周或更久 | 影响老项目交付日期和新项目选型评级 |
| 供应商限制 | 被列入限制清单、制裁、实体清单 | 自动标红供应商和关联BOM |
| 港口/航线中断 | 台风、罢工、战争、运价暴涨 | 影响进口料和海外供应商 |
| 供应集中度 | 单品牌、单产地、单供应商 | 即使无行情波动，也应给出结构性风险 |

DigiKey开发者页面说明其API可用于实时系统间信息集成和自动化订购流程，适合做库存、价格、替代料和交期接口；Trade.gov CSL可用于限制名单筛查。[3][12]

## 风险链路驾驶舱的重构建议

### 页面定位调整

“风险链路驾驶舱”应成为系统首页和主入口，展示三件事：

1. **外部风险趋势**：行情、政策、灾害、供应商、物流、原厂事件。
2. **产业链传导路径**：这些事件影响哪些材料、制程、元器件类别和BOM型号。
3. **业务反馈结论**：对新项目选型和老项目交付分别给出结论。

建议将中间部分改成三层：

```text
左侧：风险信号流
中间：EMS产业链风险图谱
右侧：BOM影响和处理建议
```

### 中间材料链路图谱

中间不再只显示“PCB → CCL → 铜箔/树脂/玻纤布”这类静态链路，而应按当前BOM自动生成：

```text
当前项目BOM命中：连接器、继电器、PCB、MOSFET、电感、铝壳

系统自动展开：
连接器 → 铜合金 / 镀锡 / 镀镍 / LCP
继电器 → 银触点 / 铜线圈 / 铁镍合金 / PA66
PCB → 铜箔 / CCL / 环氧树脂 / 玻纤布
MOSFET → 晶圆 / 引线框架 / 环氧塑封料
电感 → 铜线 / 铁氧体 / 磁芯 / 骨架
铝壳 → 铝锭 / 铝型材 / 表面处理
```

每个材料节点应展示：

- 当前价格趋势
- 近7天/30天/90天变化
- 数据来源
- 置信等级
- 影响BOM行数
- 影响项目数
- 风险等级
- 风险原因
- 最近触发事件

### 新项目BOM选型结论

新项目评审页面应输出类似结论：

```text
选型结论：有条件通过

主要原因：
1. 主控MCU为单品牌设计，原厂交期处于上行趋势，建议增加国产替代或同系列Pin-to-Pin替代。
2. PCB为8层HDI，受铜箔和CCL价格波动影响较大，建议在EVT阶段冻结叠层并提前询价。
3. 连接器使用镀金规格，受金价和交期影响，建议确认镀层必要性或增加低镀金厚度方案。
4. 铝壳结构件受铝价和表面处理产能影响，建议锁定加工供应商。
```

### 老项目交付风险结论

老项目交付风险页面应输出类似结论：

```text
交付风险：橙色

预计影响：未来4-8周存在交期延长风险

触发原因：
1. BOM中12个型号关联铜、锡、镍价格上行。
2. 关键连接器供应商库存低于安全线。
3. 华南地区台风预警可能影响PCB和连接器供应商出货。
4. 某功率器件原厂出现PCN，替代验证周期预计4周。

建议动作：
采购：提前锁定8周需求；研发：确认替代料；项目：更新交付缓冲；供应链：跟踪供应商产能。
```

## 数据源体系建议

### 数据源分层

| 层级 | 数据类型 | 示例来源 | 系统用途 |
|---|---|---|---|
| S级 | 官方、交易所、政府、原厂 | BIS、USTR、Trade.gov、USGS、NOAA、LME、SHFE、原厂PCN | 自动提级、高置信预警 |
| A级 | 行业协会、授权数据服务、专业行情平台 | SEMI、IPC、SMM、Mysteel、DigiKey API、Mouser API | 行情、产能、库存、趋势判断 |
| B级 | 行业媒体、供应商公告、物流平台 | 产业新闻、港口公告、供应商通知 | 辅助判断和早期信号 |
| C级 | 人工录入、公众号摘要、销售反馈 | 采购反馈、业务群消息、公众号截图 | 需人工确认后进入风险池 |

### 建议优先接入清单

第一优先级：直接影响风险提级

- SMM：铜、铝、锡、镍、锌、铅、银、锂、钴、稀土、半导体、不锈钢
- Mysteel：冷轧、热轧、不锈钢、硅钢、钢厂检修、库存、国际钢市
- SHFE：铜、铝、锌、铅、镍、锡、黄金、白银、不锈钢、螺纹钢、热卷
- LME：铜、铝、镍、锡、锌、铅、钴
- DigiKey/Mouser/LCSC：库存、价格、交期、替代料
- BIS/USTR/Trade.gov：出口管制、关税、限制清单
- USGS/GDACS/NOAA：中国外区域灾害和天气风险

第二优先级：增强行业判断

- SEMI：晶圆、半导体材料、设备、封测趋势
- IPC/Global Electronics Association：EMS行业、PCB、电子制造政策与供应链情报
- 原厂官网/PCN/EOL/RSS：器件生命周期
- 港口/航运/物流平台：运输中断和运价
- 地方政府/应急管理/环保/电力公告：限电、环保、停产

第三优先级：人工和半自动数据

- 公众号内容：当前微信内容无法直接读取时，可先支持人工粘贴、截图OCR、链接摘要、邮件转发。
- 供应商报价单和涨价函：通过附件上传，由LLM抽取结构化字段。
- 采购反馈：手动录入后进入“待确认风险池”。

## 风险评分模型建议

### 总体评分

建议使用多因子评分，不再单纯依赖价格。

```text
总风险分 = 行情趋势分 × 25%
        + 供应紧张分 × 20%
        + 政策合规分 × 15%
        + 灾害区域分 × 10%
        + BOM暴露度 × 15%
        + 替代难度 × 10%
        + 数据置信度调整 × 5%
```

### 自动提升风险等级规则

以下情况应自动提升风险等级：

| 触发条件 | 自动动作 |
|---|---|
| S级来源出现出口管制/实体清单/关税变化 | 直接提升至橙色或红色 |
| 原厂PCN/EOL/LTB命中BOM型号 | 直接提升至橙色，若无替代料则红色 |
| 关键材料7日涨幅超过阈值且命中高用量BOM | 提升一级 |
| 供应商所在地出现红色灾害事件 | 提升一级并标记区域风险 |
| 分销库存低于安全库存且交期拉长 | 提升至橙色 |
| 单一品牌/单一供应商且无替代料 | 至少黄色，叠加事件后橙色 |
| 数据缺失但BOM关键度高 | 显示灰色待确认，不允许显示正常 |

### 趋势反馈机制

系统应建立风险信号的生命周期：

```text
发现信号
→ 结构化解析
→ 匹配产业链节点
→ 匹配BOM型号
→ 计算风险分
→ 生成解释
→ 分派采购/研发/项目动作
→ 跟踪处理结果
→ 反馈模型权重
```

这个闭环能让系统从“展示信息”变成“持续审视趋势并反馈决策”。

## LLM接入建议

LLM不适合直接做价格事实来源，也不适合替代权威行情API。但LLM非常适合处理非结构化信息、行业判断、链路推理和报告生成。

### 最值得接入LLM的模块

| 模块 | LLM作用 | 是否推荐 |
|---|---|---|
| 行情/新闻/公告解析 | 从新闻、公告、PCN、涨价函中抽取事件、对象、时间、影响 | 强烈推荐 |
| BOM分类和材料拆解 | 将BOM型号/描述归类到元器件类型，并映射上游材料 | 强烈推荐 |
| 风险链路推理 | 判断一个事件会影响哪些材料、器件类别、项目 | 强烈推荐 |
| 采购/研发/项目建议生成 | 根据风险原因生成可读建议和处理动作 | 强烈推荐 |
| 每日/每周风险简报 | 自动总结新增风险、升级风险、已解除风险 | 强烈推荐 |
| 供应商邮件/涨价函解析 | 提取涨价幅度、生效时间、型号范围、原因 | 强烈推荐 |
| 原厂PCN/EOL文档解析 | 提取生命周期、替代型号、最后下单日 | 强烈推荐 |
| 多源冲突判断 | 解释为什么一个源显示涨价，另一个源显示平稳 | 推荐 |
| 自动写代码爬虫 | 不建议让LLM直接在线执行，应由规则化采集器完成 | 不推荐直接做 |

### LLM架构建议

建议采用“规则引擎 + 数据源API + LLM分析层”的组合：

```text
数据采集器
→ 原始事件池
→ 规则清洗和去重
→ LLM结构化抽取
→ 行业知识图谱匹配
→ 风险评分引擎
→ LLM生成解释和建议
→ 人工确认 / 自动预警
```

### 可接入模型方式

| 接入方式 | 适合场景 | 建议 |
|---|---|---|
| 网宿网关 | 企业统一网关、权限控制、日志审计、模型路由 | 适合作为正式生产方案 |
| 个人 DeepSeek API | 快速验证、低成本试点 | 适合MVP和内部试用 |
| 本地模型 | 数据敏感、离线环境 | 可作为后期方案 |
| 混合模式 | 敏感数据脱敏后走云端，内部数据走本地 | 推荐长期架构 |

### LLM输入输出边界

LLM输入应尽量是结构化上下文，而不是把整个系统数据直接丢给模型。

推荐输入：

```json
{
  "event": "SMM 1#电解铜价格7日上涨",
  "source_level": "A",
  "affected_materials": ["copper", "copper_foil", "copper_alloy"],
  "bom_hits": ["PCB", "connector", "wire_harness", "relay"],
  "project_context": {
    "project_stage": "MP",
    "delivery_window_days": 45,
    "single_source_items": 8
  }
}
```

推荐输出：

```json
{
  "risk_level_suggestion": "ORANGE",
  "reasoning": "铜价上涨同时命中PCB、连接器和线束，且当前项目45天内有交付窗口。",
  "procurement_action": "锁定未来8周铜相关物料需求，向PCB和线束供应商确认报价有效期。",
  "rd_action": "检查高铜耗连接器和线束规格是否有替代方案。",
  "confidence": 0.82
}
```

### LLM必须受控的地方

- 数值价格必须来自行情源，不能由LLM生成。
- 风险等级最终应由评分引擎决定，LLM只能给建议和解释。
- LLM输出必须保留来源引用。
- 涉及供应商黑名单、出口管制、关税，必须以官方源为准。
- 个人DeepSeek接入时，BOM客户名、供应商报价、商业敏感字段应脱敏。

### 后端新增模块

| 模块 | 作用 |
|---|---|
| `industry_chain_library` | EMS行业全链路知识库，维护元器件、材料、制程、供应区域、风险因子 |

| `bom_exposure_engine` | 计算风险事件命中哪些BOM行和项目 |
| `risk_scoring_engine` | 多因子风险评分和自动提级 |
| `llm_analysis_service` | 事件解析、链路推理、建议生成、报告生成 |
| `human_review_queue` | 对低置信度、公众号、人工反馈进行人工确认 |

### 前端页面调整

| 页面 | 调整建议 |
|---|---|
| 风险链路驾驶舱 | 改成风险信号流 + EMS链路图谱 + BOM影响结论 |
| 材料链路库 | 改成元器件类型驱动的材料链路，不再只是材料价格列表 |

| 行情与事件中心 | 展示所有行情、政策、灾害、库存、PCN/EOL事件 |
| 策略与优选库 | 按风险类型给出锁价、备货、替代、认证、供应商切换建议 |

### 数据模型调整

核心对象建议改为：

```text
RiskEvent：风险事件
Source：数据来源
IndustryNode：产业链节点
MaterialNode：材料节点
ComponentCategory：元器件类别
BomItem：BOM行
Project：项目
Exposure：风险暴露关系
RiskAssessment：风险评估结果
Recommendation：建议动作
ReviewRecord：人工确认记录
```

关键关系：

```text
RiskEvent → Source
RiskEvent → IndustryNode
IndustryNode → MaterialNode
MaterialNode → ComponentCategory
ComponentCategory → BomItem
BomItem → Project
RiskAssessment → Recommendation
```

## 分阶段落地建议

### 第一阶段：把驾驶舱逻辑改正确

目标是让系统从静态展示变成“事件 → 链路 → BOM影响”。

范围：

- 重构风险链路驾驶舱中间区域
- 建立EMS行业链路知识库
- 建立BOM元器件分类到上游材料的映射
- 风险等级从价格单因子改为多因子
- 数据不足显示灰色，而不是正常
- 输出新项目选型结论和老项目交付风险结论

### 第二阶段：接入核心数据源

目标是让系统具备基础预警能力。

范围：

- SMM / Mysteel API配置预留和接口适配
- LME / SHFE行情抓取或API接入
- BIS / USTR / Trade.gov政策源接入
- USGS / GDACS / NOAA灾害天气源接入
- DigiKey / Mouser / LCSC库存和交期源接入
- 原厂PCN/EOL手动上传和半自动解析

### 第三阶段：引入LLM分析层

目标是提升非结构化信息处理能力和分析效率。

范围：

- 接入网宿网关或DeepSeek API
- 支持涨价函、PCN、邮件、公告解析
- 支持事件影响链路推理
- 支持自动生成采购/研发/项目建议
- 支持日报、周报和领导汇报摘要
- 支持人工确认和模型反馈

### 第四阶段：风险运营闭环

目标是让系统成为日常供应链风险工作台。

范围：

- 风险任务分派
- 处理状态跟踪
- 风险解除和复盘
- 供应商响应记录
- 替代料验证进度
- 风险命中准确率统计

## 建议优先修改的系统结果

### 风险链路驾驶舱首页

首页应展示：

```text
今日新增风险事件：12条
自动提级BOM型号：18个
受影响项目：5个
高风险交付项目：2个
建议立即处理事项：7项
```

中间链路展示：

```text
台风/地震/政策/行情/库存/PCN
→ 产业链节点
→ 材料/制程
→ 元器件类别
→ BOM型号
→ 项目风险
```

### 材料链路库

材料链路库应从“材料列表”改为“元器件上游组成库”：

```text
选择：连接器
显示：铜合金、镀金、镀锡、镀镍、LCP、PBT、PA66、电镀制程
关联行情：铜、金、锡、镍、工程塑料、环保限产
影响BOM：JST-xxx、Molex-xxx、TE-xxx
当前风险：橙色
原因：铜价上行 + 镀锡供应趋紧 + 交期拉长
```

### BOM分析结果

每个BOM应增加两个结论：

| 结论类型 | 示例 |
|---|---|
| 选型评审结论 | “不建议新项目继续导入该MCU，原因是单品牌、库存低、替代验证周期长。” |
| 交付风险结论 | “未来4-8周存在连接器和PCB交付风险，建议锁定供应商产能。” |

## 需要确认的实施边界

1. SMM、Mysteel这类专业行情源如果有API账号，可以做真实自动取数；如果没有账号，先做来源链接、字段映射和接口预留。
2. 微信公众号当前不能直接读取，可以先支持人工粘贴、截图OCR、邮件转发或手工录入。
3. LLM建议先以DeepSeek或网宿网关做“分析层”，不要直接让LLM决定最终价格和风险等级。
4. 第一阶段重点不是接完所有API，而是把系统的链路逻辑、风险模型和页面表达改正确。
5. 对领导汇报而言，最重要的是让系统看起来像一个“EMS供应链风险雷达”，而不是一个材料价格看板。
