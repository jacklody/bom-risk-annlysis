# 飞书行情机器人 — 配置指南

## 它能做什么

采购/工程师在微信看到行情文章 → **转发到飞书群（5秒）** → 机器人自动解析 → 入库生成事件 → 回复卡片展示结果。

```
微信文章 → 转发到飞书群 → 机器人监听 → 自动提取品牌/品类/涨幅/交期
                                     → 调用行情收件箱API入库
                                     → 回复卡片显示识别结果
                                     → 前端"待复核队列"可见
```

## 第一步：创建飞书应用

1. 登录 [飞书开放平台](https://open.feishu.cn/)
2. 创建「企业自建应用」
3. 应用名称：`行情情报机器人`
4. 获取 **App ID** 和 **App Secret**（凭据与基础信息页）

### 添加权限

在「权限管理」中添加：
- `im:message` — 获取群聊消息
- `im:message:send_as_bot` — 机器人发消息
- `im:chat:readonly` — 读取群信息

### 配置事件订阅

在「事件订阅」中：
1. 配置**请求地址**：`https://你的服务器/api/feishu/webhook`（本地开发可用 ngrok/frp 穿透）
2. 添加事件：`im.message.receive_v1`（接收消息）
3. 保存时会发一条验证请求，确保你的服务已启动且网络可达

### 发布应用

1. 在「版本管理与发布」中创建版本
2. 审核通过后发布
3. **将机器人添加到目标飞书群**（群设置 → 群机器人 → 添加机器人）

## 第二步：配置 .env

在 `backend/.env` 添加：

```env
# 飞书行情机器人
FEISHU_APP_ID=cli_xxxxxxxxxxxxxxxx
FEISHU_APP_SECRET=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
FEISHU_VERIFICATION_TOKEN=xxxxxxxxxxxxxxxx
```

## 第三步：本地开发穿透

本地开发时飞书无法回调到 `localhost`，需要用内网穿透：

```bash
# 方式1：ngrok
ngrok http 8001

# 方式2：frp
# 配置 frpc.ini 将外网端口映射到本地8001

# 方式3：Cloudflare Tunnel
cloudflared tunnel --url http://localhost:8001
```

拿到公网URL后（如 `https://xxx.ngrok-free.app`），更新飞书应用的事件订阅地址：
`https://xxx.ngrok-free.app/api/feishu/webhook`

## 第四步：验证

1. 启动后端：`uvicorn app.main:app --port 8001`
2. 确认API可访问：`GET /api/feishu/status`
   ```json
   {"configured": true, "app_id": "cli_xxx...", "has_secret": true}
   ```
3. 在配置的飞书群中发送一段行情文本：
   ```
   TDK高容MLCC C3225X5R1A226M250AC缺货，涨价10%-20%，交期延长至16周
   ```
4. 机器人应在3秒内回复一张卡片，展示识别结果
5. 登录BOM系统 → 行情情报中心 → 情报录入 → 待复核队列，查看信号

## 支持的文本格式

机器人能识别以下类型的内容：

| 类型 | 示例 |
|------|------|
| 涨价通知 | "某品牌MCU涨价15%，7月1日起执行" |
| 缺货通知 | "国巨MLCC 47uF 0805 缺货，交期12周以上" |
| 停产通知 | "STM32F103C8T6 EOL，最后采购日2026-12-31" |
| 灾难影响 | "日本瑞萨工厂火灾，影响MCU产能" |
| 政策变化 | "美国对华芯片出口管制升级，影响AI芯片" |
| 微信文章转发 | 直接复制微信公众号文章内容 |

## 置信度规则

| 来源特征 | 置信度 | 处理后状态 |
|---------|--------|-----------|
| 含"涨价函""原厂通知"等 | ≥75% | 自动确认 → 生成事件 |
| 有具体涨幅%、交期周数 | 50-74% | 待复核 |
| 公众号/微信转发 | 降权60% | 观察（不自动生成事件） |
| 含"据说""传闻" | <40% | 仅观察 |

## 注意事项

- 飞书要求3秒内返回HTTP 200，机器人服务已做了异步处理
- 公众号来源自动降权，不会因一篇公众号文章直接触发红色预警
- 机器人**不会**自动拉取未转发的公众号文章（微信无公开API）
- 可以部署到公网服务器后关闭内网穿透
