# BOM物料风险预警系统：优化版系统设计方案 v3.1

> 更新日期：2026-06-25  
> 修订依据：《BOM物料风险预警系统 v3.0 专业评审与优化建议》  
> 修订方向：从“全链路覆盖优先”调整为“可靠性校准、分品类建模、预测验证闭环优先”

## 1. 修订后的设计判断

v3.0 的方向仍然成立：BOM 风险预警需要从器件本体延伸到上游材料、加工工艺、产能、公司实体和行业需求。但评审意见指出了一个关键问题：不是所有上游链条都能同等可靠地传导到 BOM 物料。铜价影响 PCB、继电器、电感、连接器，这类传导直接且可验证；硅片、光刻胶、塑封料影响 MCU 或 IC 价格，这类传导弱得多，直接用材料涨幅推导芯片风险会误导用户。

v3.1 的核心修订是把系统从“尽可能完整地画出供应链网络”升级为“对每条风险传导链标注可靠性、时间滞后、转嫁率和验证结果”。系统不再强行给每颗物料一个看似精确的分数，而是根据数据是否充分、传导是否可靠、历史验证是否有效，分别输出：明确风险、趋势关注、信息不足或弱关联提示。

```text
v3.0：BOM → 上游材料/工艺/公司/行业 → AI综合评分
v3.1：BOM → 传导链可靠性校准 → 分品类模型 → 预测验证 → 可解释预警
```

## 2. v3.1 相对 v3.0 的关键变化

| 评审问题 | v3.1 修订 |
|---|---|
| 置信度缺乏校准机制 | 增加“预测验证闭环”，按品类和传导类型统计准确率，反向修正评分权重 |
| 上游行情数据很多不可获取 | 区分“公开行情”“供应商确认”“代理指标”“不可评估”，不再假设所有材料都有精确行情 |
| 材料涨价不等于器件涨价 | 增加“转嫁率”和“滞后时间”，材料传导必须乘以品类转嫁系数 |
| IC 类材料传导弱 | 将物料分为“成本驱动型”和“供需驱动型”，IC 以供需、产能、交期为主，不以材料成本为主 |
| 缺少供需建模 | 增加“供需平衡分”，用库存、交期、价格快照、下游行业热度和供应商集中度计算 |
| 缺少缓冲因素 | 增加 LTA 锁价、安全库存、VMI/JIT、替代料成熟度等缓冲因子 |
| 缺少贸易政策风险 | 增加关税、出口管制、制裁清单、汇率波动风险维度 |
| 强行输出风险分 | 增加“信息不足”状态，数据不足时不给虚假低风险结论 |

## 3. 修订后的总体架构

v3.1 保留 v3.0 的上游组份网络，但在网络和评分之间增加“可靠性校准层”和“预测验证层”。这两个层是系统可信度的核心。

```text
数据采集层
├─ BOM / AVL / 替代料库 / 历史采购记录
├─ 分销商库存、价格、交期、生命周期
├─ 供应商涨价函、PCN、PDN、承认书、规格书
├─ 铜、银、铝、锡、镍、金等公开行情
├─ 覆铜板、玻纤布、树脂、铝箔等行业趋势
├─ 晶圆产能、封测交期、PCB产能、MLCC交期等代理指标
├─ 关税、出口管制、实体清单、汇率
└─ 汽车、光伏、储能、AI服务器、工业控制等行业订单信号

结构化与知识层
├─ 型号标准化
├─ 品类识别
├─ 规格书解析
├─ 上游组份模板
├─ 公司实体映射
├─ 数据可获取性标注
└─ 证据片段保存

可靠性校准层
├─ 传导链可靠性：已验证 / 理论传导 / 弱关联
├─ 品类驱动类型：成本驱动 / 供需驱动 / 混合驱动
├─ 转嫁率：材料涨幅传到器件价格的比例
├─ 滞后时间：风险从上游传到采购价格或交期的周期
├─ 证据强度：涨价函 > 历史验证 > 行业报告 > 行情趋势 > 单点新闻
└─ 信息充分度：充足 / 部分充足 / 不足

风险计算层
├─ 本体信号分
├─ 上游材料传导分
├─ 供需平衡分
├─ 工艺产能分
├─ 公司实体风险分
├─ 贸易政策分
├─ BOM影响分
└─ 缓冲因子扣减

预测验证层
├─ 记录每次预警的对象、原因、时间窗口和预期结果
├─ 到期后自动比对实际价格、交期、库存和生命周期变化
├─ 按品类、传导链、数据源统计命中率
└─ 反向修正权重、置信度和展示策略

输出层
├─ 单颗物料风险依据链
├─ PCBA共同上游暴露
├─ 项目级风险影响
├─ 信息不足提示
├─ 预测准确率说明
└─ 处置建议
```

## 4. 品类分层：成本驱动与供需驱动分开建模

电子元器件的风险不应套用同一个模型。v3.1 把 BOM 物料分为三类：成本驱动型、供需驱动型、混合驱动型。

### 4.1 成本驱动型品类

材料成本占比较高，上游价格容易传导到器件报价。这类品类适合优先做 MVP，也适合用“材料行情 + 涨价函 + 规格书”建模。

| 品类 | 主要上游 | 可靠性 | 典型传导 |
|---|---|---|---|
| PCB | 铜箔、覆铜板、玻纤布、树脂 | 高 | 铜价/覆铜板 → PCB报价 |
| 功率电感/变压器 | 铜线、磁芯、骨架、绝缘材料 | 高 | 铜价 → 漆包线 → 电感/变压器 |
| 继电器 | 银触点、铜线圈、铁芯、塑胶 | 高 | 银价/铜价 → 继电器 |
| 连接器 | 铜合金端子、镀金/镀锡、塑胶 | 中高 | 铜价/金价/电镀 → 连接器 |
| 铝电解电容 | 阳极铝箔、阴极铝箔、电解液 | 中高 | 铝箔/铝价 → 铝电解电容 |
| 线束/端子 | 铜材、绝缘皮、镀层 | 高 | 铜价 → 线束/端子 |

这类品类的风险输出可以较明确，例如“铜价上涨 12%，PCB 铜箔暴露高，传导可靠性高，预计 1–3 个月内报价压力上升”。

### 4.2 供需驱动型品类

材料成本占比低，价格和交期更多由产能、订单、产品生命周期、供应商策略决定。对 IC 类器件，不能因为硅片、光刻胶、塑封料涨价就直接判定芯片涨价。

| 品类 | 主导风险 | 材料传导权重 | 更可靠的判断信号 |
|---|---|---:|---|
| MCU | 8寸/12寸产能、车规/工业需求、原厂分配 | 低 | 分销商交期、原厂PCN、生命周期、库存趋势、行业订单 |
| 模拟芯片 | 成熟制程产能、测试周期、工业/汽车订单 | 低 | 交期拉长、品牌集体缺货、替代料同步紧张 |
| 电源芯片 | BCD制程、封测产能、汽车/光伏/储能需求 | 低 | 交期、库存、供应商涨价函、应用行业热度 |
| 数字芯片 | 制程产能、封装、下游需求 | 低 | 生命周期、库存、供需变化 |
| 普通 IC | 原厂策略、渠道库存、封测排产 | 低 | 分销库存、价格快照、原厂公告 |

这类品类的输出应更谨慎，例如“疑似成熟制程产能压力，交期趋势需观察”，而不是“硅片上涨导致 MCU 涨价”。

### 4.3 混合驱动型品类

既受材料影响，也受供需格局影响。系统要同时看材料、交期、行业需求和供应商涨价函。

| 品类 | 成本因素 | 供需因素 | 判断方式 |
|---|---|---|---|
| MLCC | 钛酸钡、镍、铜、银钯 | 车规、高容值、小尺寸需求 | 材料只作为辅助，交期和库存是主信号 |
| 薄膜电容 | 聚丙烯薄膜、喷金材料、树脂 | 新能源、逆变器需求 | 材料 + 行业订单共同判断 |
| 安规电容 | 金属化薄膜、阻燃树脂 | 电源、家电、认证周期 | 供应商通知更可靠 |
| 功率模块 | 铜、银烧结、陶瓷基板、芯片 | 新能源车、光伏、储能 | 材料 + 产能 + 下游行业同时评分 |
| 压敏/热敏 | 陶瓷粉体、银电极、铜引线 | 家电、新能源、保护需求 | 材料信号中等，供应商交期更重要 |

## 5. 传导链可靠性分级

每条“上游 → 器件 → BOM”的关系都必须带可靠性等级。评分和展示都应区别对待。

| 等级 | 定义 | 示例 | 评分系数 | 展示方式 |
|---|---|---|---:|---|
| 已验证传导 | 有涨价函、历史数据、供应商反馈或行业报告确认 | 铜 → PCB，银 → 继电器，铝箔 → 铝电解 | 1.0 | 可作为主要风险依据 |
| 高可信理论传导 | 材料成本占比较高，但暂缺本企业验证 | 铜 → 电感，铜合金 → 连接器 | 0.7 | 标注“高可信推断” |
| 理论传导 | 有技术关系，但成本占比或商业传导不明确 | 钛酸钡 → MLCC，封装基板 → IC | 0.5 | 仅作为辅助依据 |
| 弱关联 | 间接关联、成本占比低或无法证明传导 | 光刻胶 → MCU涨价，环氧树脂 → IC涨价 | 0.2 | 不单独触发高风险 |
| 不可评估 | 缺少关键数据或关系不确定 | 未知芯片工艺/未知供应链 | 0 | 输出“信息不足” |

系统展示时不能只给颜色，还要告诉用户这条链是否可靠：

```text
风险依据链：铜价上涨 → 覆铜板/铜箔 → 四层PCB报价压力
传导可靠性：已验证传导
预计滞后：1–3个月
证据：LME铜价30天上涨 + PCB供应商报价有效期缩短 + 历史项目中PCB成本占比高
```

## 6. 转嫁率与滞后时间模型

材料涨价需要经过供应商采购、库存消化、报价周期、客户议价、合同条款，才会传导到 BOM 采购价格。v3.1 增加品类级参数。

| 品类 | 材料转嫁率估算 | 滞后时间 | 说明 |
|---|---:|---|---|
| PCB | 60%–80% | 1–3个月 | 铜价和覆铜板变化传导较快，报价有效期短 |
| 电感/变压器 | 50%–70% | 2–4个月 | 铜线成本占比较高 |
| 铝电解电容 | 40%–60% | 3–6个月 | 铝箔占比高，但供应商库存缓冲较明显 |
| 继电器 | 30%–50% | 2–4个月 | 大功率银触点继电器更敏感 |
| 连接器 | 20%–40% | 3–6个月 | 附加值和加工费缓冲较大 |
| MLCC | 10%–30% | 3–6个月 | 定价受供需周期影响更强 |
| MCU/IC | <10% | 不作为主模型 | IC价格主要由供需、产能、原厂策略决定 |

计算时不再用“材料涨幅直接映射风险”，而是：

```text
上游材料传导分 = 材料涨幅
              × 材料暴露系数
              × 品类转嫁率
              × 传导可靠性系数
              × 证据强度系数
              × 时间窗口系数
```

如果铜价上涨 10%，PCB 的风险可能明显上升；如果硅片上涨 10%，MCU 的材料传导分仍然可能很低，除非同时出现晶圆厂涨价、交期拉长、原厂调价或供应商涨价函。

## 7. 供需平衡模型

电子元器件很多风险来自供需，而不是成本。v3.1 将“供需平衡”作为独立主线。

### 7.1 输入指标

| 指标 | 数据来源 | 说明 |
|---|---|---|
| 分销库存趋势 | 立创、华秋、贸泽、得捷、云汉等 | 总库存下降、渠道数减少是直接信号 |
| 工厂交期 | Mouser、Digi-Key、供应商报价、采购反馈 | 交期拉长比材料价格更能反映产能紧张 |
| 价格快照 | 分销商价格、采购历史价 | 多渠道同步上涨说明供需变化 |
| 替代料可得性 | AVL、器件搜索引擎、历史替代记录 | 替代料也缺货说明品类风险扩大 |
| 下游行业热度 | 汽车、AI服务器、光伏、储能、工业控制新闻与订单 | 判断是否发生产能挤占 |
| 供应商集中度 | BOM品牌分布、供应商数量 | 单一品牌或单一渠道风险更高 |

### 7.2 供需平衡评分

```text
供需平衡分 = 库存下降分 × 0.25
          + 交期拉长分 × 0.30
          + 多渠道价格上涨分 × 0.15
          + 替代料紧张分 × 0.15
          + 行业需求热度分 × 0.10
          + 供应商集中度分 × 0.05
```

对 IC、MLCC、功率模块等供需驱动型品类，供需平衡分的权重要高于上游材料分。

## 8. 数据可获取性分级

v3.1 不再假设每种材料都有公开价格。系统对每个上游节点标注数据可获取性。

| 数据等级 | 含义 | 示例 | 系统处理 |
|---|---|---|---|
| A级公开行情 | 可稳定获取公开价格或指数 | 铜、铝、银、锡、镍、金 | 可直接用于趋势判断 |
| B级行业趋势 | 有行业报告、上市公司公告或媒体趋势 | 覆铜板、玻纤布、树脂、铝箔 | 用于趋势，不做精确涨幅 |
| C级代理指标 | 无价格，使用交期、涨价函、库存作为代理 | MLCC烧结产能、封测排产、引线框架 | 只做间接判断 |
| D级私有信息 | 主要来自供应商报价、采购反馈 | 具体型号加工费、封测排产 | 需企业内部沉淀 |
| E级不可评估 | 缺少有效公开或内部数据 | 某些小众粉体、非公开供应链 | 输出信息不足 |

示例：

```text
钛酸钡粉体 → C级代理指标
原因：公开价格少，直接行情不可得
替代判断：观察MLCC供应商涨价函、高容值MLCC交期、村田/国巨等行业动态
```

## 9. 信息不足状态

“信息不足”不是失败状态，而是防止系统误导用户的必要状态。以下情况不应强行输出绿色或橙色：

| 场景 | 输出 |
|---|---|
| 无法识别品类 | 信息不足：无法识别物料品类，建议补充品牌/型号/规格 |
| 无规格书且品类模板不适用 | 信息不足：缺少材料或封装线索 |
| IC无法判断工艺、产能、交期 | 信息不足：仅可基于本体库存和交期判断 |
| 上游节点属于E级不可评估 | 信息不足：该上游行情无稳定数据源 |
| 传导链属于弱关联且无证据 | 弱关联提示：不触发高风险，只作为背景信息 |

页面建议展示：

```text
状态：信息不足
当前可判断：本体库存正常，生命周期 Active
当前不可判断：晶圆厂、封测厂、工艺节点、上游材料传导
建议补充：规格书、供应商报价、原厂PCN/PDN、历史采购价格
```

## 10. 缓冲因子模型

同样的上游风险，对不同企业的影响不同。长期协议、库存和替代料会降低短期风险。

| 缓冲因素 | 降低风险的逻辑 | 建议字段 |
|---|---|---|
| LTA锁价 | 合同周期内材料涨价不一定传到采购价 | contract_price_locked、contract_end_date |
| 安全库存 | 短期不用按新价格采购 | on_hand_inventory、safety_stock_days |
| VMI/JIT库存 | 供应商侧已有库存缓冲 | supplier_buffer_days |
| 多品牌替代 | 可切换供应商降低涨价压力 | approved_alternatives_count |
| 国产替代成熟 | 进口限制或原厂涨价时有替代空间 | local_alternative_ready |
| 低用量/低金额 | 对项目成本影响较小 | annual_usage、bom_cost_share |

```text
最终风险分 = 原始风险分 - 缓冲因子分
缓冲因子分 = LTA锁价 + 安全库存 + 替代料成熟度 + 低成本占比
```

缓冲因子不能删除风险，只能降低短期紧急程度。例如铜价上涨仍然是 PCB 成本风险，但如果企业已有 3 个月锁价和安全库存，告警应从“立即处理”降为“关注后续采购窗口”。

## 11. 贸易政策与汇率风险

电子供应链受国际政策影响明显。v3.1 增加贸易政策风险维度，主要覆盖：

| 风险类型 | 影响对象 | 判断依据 |
|---|---|---|
| 关税/反倾销税 | 进口元器件、PCB、连接器、线束 | 政策公告、海关税则、供应商通知 |
| 出口管制 | 高端芯片、EDA、半导体设备、材料 | BIS公告、实体清单、原厂供货限制 |
| 制裁/实体清单 | 特定公司和供应链 | 官方名单、企业公告、供应商反馈 |
| 汇率波动 | 以美元计价的原材料和进口器件 | USD/CNY、采购币种、报价有效期 |
| 物流限制 | 跨境供货、保税区、特殊材料 | 物流通知、港口/航线异常 |

贸易政策风险不一定立刻导致涨价，但会影响可采购性、交期和替代方案。对进口品牌、单一来源器件、海外封测或受限行业物料，权重要更高。

## 12. 重构后的风险评分模型

固定权重不适合所有品类。v3.1 按品类驱动类型选择评分模型。

### 12.1 成本驱动型模型

适用于 PCB、继电器、连接器、电感、变压器、铝电解、线束等。

```text
风险分 = 本体信号分 × 0.20
      + 上游材料传导分 × 0.30
      + 供需平衡分 × 0.15
      + 工艺产能分 × 0.10
      + 贸易政策分 × 0.10
      + BOM影响分 × 0.15
      - 缓冲因子分
```

### 12.2 供需驱动型模型

适用于 MCU、模拟芯片、数字芯片、电源芯片、普通 IC。

```text
风险分 = 本体信号分 × 0.25
      + 供需平衡分 × 0.25
      + 工艺产能分 × 0.15
      + 行业冲击分 × 0.10
      + 贸易政策分 × 0.10
      + BOM影响分 × 0.15
      + 上游材料传导分 × 0.05上限约束
      - 缓冲因子分
```

说明：IC 类上游材料传导分可以参与解释，但不能单独把风险推到橙色或红色。只有当材料事件同时伴随晶圆厂涨价、封测排产、交期拉长、供应商涨价函或多渠道库存下降时，才提升风险等级。

### 12.3 混合驱动型模型

适用于 MLCC、薄膜电容、功率模块、压敏、热敏、安规电容等。

```text
风险分 = 本体信号分 × 0.20
      + 上游材料传导分 × 0.20
      + 供需平衡分 × 0.20
      + 工艺产能分 × 0.15
      + 行业冲击分 × 0.10
      + 贸易政策分 × 0.05
      + BOM影响分 × 0.10
      - 缓冲因子分
```

### 12.4 证据强度系数

| 证据 | 系数 | 说明 |
|---|---:|---|
| 供应商涨价函明确说明原因 | 1.0 | 最强证据 |
| 企业历史采购价已上涨 | 1.0 | 已发生事实 |
| 多个分销商同步价格/交期变化 | 0.8 | 高可信市场信号 |
| 行业报告或原厂公告 | 0.7 | 可信但需映射到具体物料 |
| 公开材料行情单独上涨 | 0.5 | 只说明上游压力 |
| 单篇媒体或KOL传闻 | 0.2 | 仅记录，不触发高风险 |

## 13. 预测验证闭环

系统每次发出预警，都要把“预测”记录下来。到期后自动验证，不断校准模型。

### 13.1 预警记录字段

```sql
CREATE TABLE risk_predictions (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    bom_item_id INTEGER,
    mpn VARCHAR(128),
    manufacturer VARCHAR(128),
    component_category VARCHAR(64),
    risk_type VARCHAR(64),
    predicted_risk_level VARCHAR(16),
    predicted_outcome VARCHAR(128),       -- price_up / lead_time_extend / stock_out / lifecycle_change
    expected_window_days INTEGER,
    evidence_chain_id INTEGER,
    model_version VARCHAR(32),
    confidence FLOAT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    verify_after DATETIME,
    verified_at DATETIME,
    actual_outcome VARCHAR(128),
    hit_result VARCHAR(32),               -- hit / partial_hit / miss / unverifiable
    verification_note TEXT
);
```

### 13.2 验证逻辑

```text
预警发出
→ 记录预测对象、风险类型、风险等级、依据链、预期时间窗口
→ 到期后自动查询价格、交期、库存、生命周期和采购历史
→ 判断是否命中
→ 统计命中率
→ 修正对应品类、传导链和数据源权重
```

示例：

| 预测 | 验证方式 | 命中判断 |
|---|---|---|
| PCB因铜价上涨，预计1–3个月报价上升 | 比对采购价/供应商报价/PCB厂通知 | 价格上涨或报价有效期缩短 |
| 继电器因银价上涨，预计2–4个月调价 | 比对供应商报价和涨价函 | 出现涨价函或采购价上涨 |
| MCU因8寸产能紧张，预计交期拉长 | 比对分销商交期和供应商反馈 | 交期增加或库存下降 |

### 13.3 模型校准

按以下维度统计准确率：

| 统计维度 | 用途 |
|---|---|
| 品类准确率 | 判断某类物料模型是否可靠 |
| 传导链准确率 | 判断铜→PCB、银→继电器等链条是否有效 |
| 数据源准确率 | 判断某数据源是否经常误报 |
| 风险类型准确率 | 区分涨价、缺货、交期、生命周期预测能力 |
| 时间窗口准确率 | 判断滞后时间是否合理 |

如果某条传导链连续多次误报，系统自动降低该链条权重；如果某类涨价函验证命中率高，系统提高该数据源和该传导链的证据强度。

## 16. MVP 优先级调整

评审意见建议先做 5 个高可靠性品类，这是正确方向。v3.1 将 MVP 调整为“先验证可靠链条，再扩展全品类”。

### 16.1 MVP范围

| 范围 | 内容 |
|---|---|
| 品类 | PCB、铝电解电容、继电器、连接器、功率电感/变压器 |
| 上游材料 | 铜、银、铝 |
| 数据源 | 公开金属行情、供应商涨价函、分销商价格/交期、历史采购价 |
| 模型 | 成本驱动型模型、传导链可靠性分级、转嫁率与滞后时间 |
| 页面 | BOM风险列表、依据链详情、预测验证记录 |
| 输出 | 涨价风险、交期风险、受影响PCBA和项目、处置建议 |

### 16.2 MVP不做的内容

| 暂缓内容 | 原因 |
|---|---|
| 全量IC制造归属链 | 公开数据不足，容易产生伪精确结论 |
| 全部材料行情 | 很多材料无公开价格，先用代理指标和供应商通知 |
| 高级图谱可视化 | 初期先用依据链列表和简单关系图，避免前端复杂度过高 |
| 全品类覆盖 | 先验证高可靠品类的预警准确率 |
| 自动估算所有铜银克重 | 规格书通常缺少克重，先输出敏感度和置信度 |

### 16.3 MVP交付节奏

| 阶段 | 周期 | 交付内容 |
|---|---|---|
| 第1阶段 | 1–2周 | 5个品类模板、铜银铝行情接入、涨价函解析 |
| 第2阶段 | 3–4周 | 传导链可靠性、转嫁率、滞后时间、成本驱动评分 |
| 第3阶段 | 5–6周 | BOM命中、PCBA影响、预测验证记录、前端依据链展示 |
| 第4阶段 | 7–8周 | 根据真实采购反馈校准权重，扩展连接器/电感规格书解析 |

如果已有 v0.3 的实时 API、BOM解析和风险表基础，MVP 可以优先接入后端服务，不必先做完整图数据库。

## 19. 最终系统定位

v3.1 后的系统不是“万能预测器”，而是一个带自我校准能力的 BOM 风险雷达。它承认供应链数据存在不透明和不确定性，并把这种不确定性显式呈现给用户。

系统真正要做到的是：

```text
有证据的风险 → 明确预警
有趋势但证据不足 → 标注关注
传导链弱 → 降权展示
数据不足 → 明确说不知道
预警发出后 → 到期验证并修正模型
```

这种设计比单纯追求全品类、全上游、全图谱更适合真实落地。先从 PCB、铝电解、继电器、连接器、电感/变压器这类高可靠链条做出可信结果，再逐步扩展到 MLCC、功率模块和 IC 类复杂品类，系统的可信度会更高，开发风险也更低。
