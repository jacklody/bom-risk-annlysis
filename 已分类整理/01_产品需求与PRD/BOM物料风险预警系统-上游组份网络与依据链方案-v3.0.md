# BOM物料风险预警系统：上游组份网络与依据链方案 v3.0

> 更新日期：2026-06-25  
> 基于 v2.0 主动风险发现方案扩展  
> 核心变化：从“器件本体风险”升级为“器件本体 + 二三级上游材料 + 工艺设备 + 公司/行业冲击”的完整预警依据链

## 1. 核心结论

当前 BOM 风险预警不能只看某颗物料本体的库存、交期、价格和生命周期。很多风险先发生在上游：铜、银、铝、环氧树脂、玻纤布、铜箔、硅片、光刻胶、封装基板、引线框架、键合丝、磁性材料、电解液、陶瓷粉体、薄膜、电镀材料、专用设备产能等。这些上游变化会通过材料成本、产能瓶颈、工艺良率、供应商议价和下游需求挤占，传导到 BOM 里的电容、电感、继电器、PCB、连接器、功率模块、MCU、数字芯片、模拟芯片和电源芯片。

v3.0 的系统目标是建立一张“风险依据链”：

```text
BOM行项目
  → 器件标准化型号 / 品类 / 封装 / 参数
  → 二级上游组份
  → 三级上游原料 / 化工品 / 半导体材料
  → 制造工艺 / 关键设备 / 产能瓶颈
  → 原厂 / 代工厂 / 封测厂 / 材料供应商 / 行业需求
  → 市场行情事件
  → AI综合判断
  → 单颗物料、PCBA、项目、批量生产风险
```

这张网络不是为了精确计算每一颗物料里有多少克铜、多少克银，而是为了让预警系统回答三个业务问题：

1. 这颗 BOM 物料为什么可能涨价、缺货或交期拉长。
2. 这个风险是器件本体风险，还是上游材料、工艺产能、设备限制、公司经营、行业订单冲击导致的传导风险。
3. 风险会影响哪些历史 BOM、哪些 PCBA、哪些项目、哪些可替代料，以及需要提前多久处理。

## 2. v3.0 与 v2.0 的关系

v2.0 已经建立了主动风险发现能力：API 价格库存、生命周期、供应商公告、行业媒体、KOL、企业信用、邮件和用户上传通知。v3.0 不推翻 v2.0，而是在事件结构化之后增加一层“上游组份网络推理”。

| 层级 | v2.0 已覆盖 | v3.0 新增 |
|---|---|---|
| BOM行项目 | MPN、品牌、品类、数量、替代料、历史项目命中 | 增加封装、材料暴露、工艺节点、上游依赖标签 |
| 器件本体 | 价格、库存、交期、生命周期、涨价函 | 器件结构拆解、规格书抽取、上游映射 |
| 上游材料 | 主要依赖供应商涨价原因文本 | 系统化拆出铜、银、铝、树脂、玻纤、硅片、封装材料等 |
| 工艺设备 | 未形成结构化关系 | 建立光刻、蚀刻、电镀、绕线、烧结、注塑、封装、测试等工艺依赖 |
| 公司/行业 | 原厂、供应商、行业新闻 | 关联晶圆厂、封测厂、材料商、下游行业订单冲击 |
| AI判断 | 事件置信度、风险评分 | 形成可追溯依据链，解释风险从哪里传导到 BOM |

## 3. 总体架构

v3.0 增加“上游知识图谱层”和“风险传导引擎”。原来的价格哨兵、库存哨兵、生命周期哨兵继续运行，同时增加四类新哨兵：材料行情哨兵、工艺产能哨兵、半导体产能哨兵、行业订单哨兵。

```text
数据源层
├─ BOM / 历史项目 / 替代料库
├─ 分销商 API / 器件搜索引擎 / 原厂官网 / PCN / PDN / 涨价函
├─ 规格书 / 承认书 / 物料书 / 供应商报价单
├─ 大宗商品行情：铜、银、铝、锡、镍、环氧树脂、硅、钯、金等
├─ 半导体材料行情：硅片、光刻胶、电子特气、封装基板、引线框架等
├─ PCB材料行情：铜箔、玻纤布、树脂、覆铜板、油墨、钻针等
├─ 工艺设备与产能：晶圆制造、封测、MLCC烧结、继电器触点、电镀、PCB钻孔压合等
└─ 行业需求：汽车、光伏、储能、AI服务器、工业控制、消费电子、家电等

结构化层
├─ 型号标准化
├─ 品类识别
├─ 规格书解析
├─ 组份模板匹配
├─ 公司实体解析
└─ 事件置信度评分

上游组份网络层
├─ 器件 → 组份
├─ 组份 → 原料
├─ 原料 → 工艺
├─ 工艺 → 设备/产能
├─ 器件 → 原厂/晶圆厂/封测厂
└─ 器件 → 下游行业需求

风险传导层
├─ 材料涨价传导
├─ 产能紧张传导
├─ 公司经营风险传导
├─ 行业订单挤占传导
└─ 替代料连带风险识别

输出层
├─ BOM行项目风险依据链
├─ PCBA板级影响
├─ 项目级影响
├─ 批量成本影响
└─ 处置建议
```

## 4. BOM物料到上游组份的拆解模型

系统采用“模板拆解 + 规格书增强 + 供应商知识修正”的方式。第一阶段先按品类建立标准模板，第二阶段读取规格书、承认书、RoHS/REACH 材料声明、供应商报价说明来修正模板，第三阶段把真实采购数据、供应商反馈和用户确认结果回写为企业私有知识。

### 4.2 PCB 与 PCBA 基础材料

PCB 是 PCBA 风险预警里最容易被低估的板级材料。即使 BOM 里只出现“PCB板”或“线路板”，系统也应拆成覆铜板、铜箔、玻纤布、树脂、油墨、钻针、化学药水和加工产能。

| BOM品类 | 二级上游 | 三级上游 | 工艺/设备依赖 | 主要风险传导 |
|---|---|---|---|---|
| 继电器 | 触点、线圈、簧片、铁芯、外壳、底座 | 银、铜、铁镍合金、工程塑料、漆包线 | 冲压、电镀、绕线、装配、触点铆接、寿命测试 | 银价、铜价、触点材料、汽车/家电订单 |
| 连接器 | 端子、塑胶壳、镀层、屏蔽壳 | 铜合金、金、锡、镍、LCP/PA/PBT | 冲压、电镀、注塑、自动组装 | 铜价、金价、电镀产能、汽车/服务器需求 |
| 开关 | 触点、弹片、塑胶件、外壳 | 铜、银、钢、工程塑料 | 冲压、电镀、注塑、组装 | 贵金属、塑胶料、电镀环保限制 |
| 端子/线束 | 铜材、绝缘皮、镀层 | 铜、PVC/TPE、锡、镍 | 拉丝、绞线、压接、注塑 | 铜价、汽车线束订单、塑胶料涨价 |

继电器和连接器可通过规格书增强材料估算。例如继电器规格书通常包含触点形式、触点材料、触点负载、线圈电阻、外形尺寸和重量。系统可以按以下方式推断：

```text
触点材料 = AgSnO2 / AgNi / AgCdO / 银合金
触点数量 = 1 Form A / 1 Form C / 2 Form C
额定电流 = 5A / 10A / 16A / 30A
外形尺寸 + 重量 = 物料尺寸等级
→ 估算银触点质量区间
→ 结合银价走势和触点材料供应状态
→ 形成继电器银价敏感度
```

该估算必须带置信度，不应伪装为精确值。系统展示时使用“银价敏感度：高/中/低”和“估算依据：触点材料 + 触点数量 + 额定电流 + 尺寸等级”。

## 5. 规格书与资料解析机制

用户提出的“能不能根据型号去找规格书，根据规格书拆解铜银含量”是可行方向，但要分层处理：规格书通常不会直接写出完整材料克重，系统应读取可公开字段，再结合品类模板估算材料暴露。

### 5.1 文件来源

| 来源 | 典型文件 | 用途 |
|---|---|---|
| 分销商 API | datasheet_url、产品页 | 自动下载规格书 |
| 原厂官网 | Datasheet、Application Note、PCN、PDN | 获取封装、材料、产地、生命周期 |
| 用户上传 | 承认书、规格书、报价单、涨价函、RoHS/REACH声明 | 获取更细材料和供应商说明 |
| 供应商邮件 | 调价通知、交期通知 | 提取原因、涨幅、生效日、范围 |
| 企业内部资料 | AVL、替代料库、供应商反馈 | 修正公开资料不足 |

### 5.2 解析字段

| 字段组 | 字段 | 示例 |
|---|---|---|
| 标准身份 | MPN、品牌、品类、封装、系列 | STM32F103C8T6、QFP48、MCU |
| 参数 | 额定电压、电流、容值、阻值、尺寸、温度等级 | 10A、16V、100uF、1206 |
| 材料线索 | 触点材料、电极材料、介质、磁芯、外壳、引线 | AgSnO2、Ni/Sn、Ferrite、PP film |
| 制造线索 | 封装地、产地、工艺、认证、车规等级 | AEC-Q100、Made in Malaysia |
| 风险线索 | EOL、NRND、PCN、涨价、生效日、替代型号 | Last Time Buy、Package change |

### 5.3 抽取流程

```text

  → 查询规格书链接
  → 下载 PDF / HTML / 图片
```

## 7. 风险传导模型

风险传导分为三类：成本传导、产能传导和需求挤占传导。

### 7.1 成本传导

材料上涨不等于器件立即同幅上涨。系统按“材料暴露 × 成本占比 × 供应商转嫁能力 × 时间滞后”估算影响。

```text
材料成本风险分 = 材料涨幅 × 材料暴露系数 × 成本占比系数 × 转嫁系数 × 置信度系数
```

示例：

| 场景 | 判断 |
|---|---|
| 铜价上涨 12%，连接器端子铜合金占比较高 | 连接器成本压力中高，若供应商已有涨价函则升为高风险 |
| 银价上涨 18%，继电器规格书显示 AgSnO2 触点且额定电流 30A | 继电器银价敏感度高，若品牌集中度高则进入橙色/红色 |
| 铝箔上涨 10%，BOM 中大批量使用铝电解电容 | 板级成本影响可能明显，优先检查大容量/高纹波规格 |

### 7.2 产能传导

材料价格不涨也可能缺货。产能传导关注工艺环节和设备瓶颈。

```text
产能风险分 = 工艺瓶颈强度 × 该工艺依赖度 × 替代产能可得性 × 行业需求热度
```

示例：

| 场景 | 判断 |
|---|---|
| 8寸成熟制程产能紧张 | MCU、模拟、电源管理、驱动芯片交期拉长风险上升 |
| 封测厂车规订单排满 | AEC-Q 器件、功率器件、汽车继电器可能被挤占 |
| PCB厂高层板订单饱和 | 多层 PCB、HDI、厚铜板交期风险上升 |
| MLCC 高容值车规需求增加 | 高容值、小尺寸、车规 MLCC 风险高于普通消费级 MLCC |

### 7.3 行业订单挤占

某些物料本身没有停产也没有直接涨价，但当新能源车、光伏、储能、AI服务器、机器人、工业控制等行业订单上升时，会挤占相同产线、相同封装、相同材料或相同测试资源。

```text
订单挤占风险 = 下游行业热度 × 物料行业共用度 × 供应商集中度 × BOM替代难度
```

## 8. AI综合判断输出

AI 不直接给出“涨价一定发生”的结论，而是输出带证据链的判断。

### 8.1 单颗物料输出样式

```text
物料：某品牌 16V 100uF 铝电解电容
风险等级：橙色
风险类型：上游材料涨价 + 供应商转嫁风险
依据链：
1. 品类模板显示：铝电解电容主要依赖阳极铝箔、阴极铝箔、电解液、隔离纸、铝壳。
2. 最近30天电子铝箔报价上涨，铝价处于上行区间。
3. 用户历史BOM中该规格用量高，替代品牌少。
4. 同类供应商近期涨价函提到“铝箔、电解液、能源成本上涨”。
AI判断：该型号未来1-2个月存在成本上行风险；若供应商库存少于安全线，建议提前锁价或扩展替代料。
```

### 8.2 PCBA板级输出样式

```text
PCBA：电源控制板 A
板级风险：黄色
主要传导链：
- 铜价 → PCB铜箔 / 连接器端子 / 功率电感铜线
- 8寸晶圆产能 → 电源管理IC / 运放 / 驱动芯片
- 铝箔 → 铝电解电容
影响判断：直接涨价物料数量不多，但多个关键物料共同受铜和成熟制程影响，存在集中传导风险。
```

### 8.3 项目级输出样式

```text
项目：历史项目 X
项目风险：橙色
原因：3块PCBA共同使用同系列电源芯片和同规格继电器；继电器银触点暴露高，电源芯片疑似8寸成熟制程，两个风险同时出现。
建议：
- 优先确认未来3个月需求量。
- 对继电器进行触点材料和替代型号复核。
- 对电源芯片查询原厂交期、封测地和二供。
```

## 9. 数据库与知识图谱设计

建议在现有 SQLite 版本上先做轻量表扩展，后续迁移到 PostgreSQL + 图数据库能力。第一阶段可用关系表表达图关系，不必一开始引入复杂图数据库。

### 9.1 核心实体

| 实体 | 说明 |
|---|---|
| component_category | 器件品类，如 MCU、铝电解电容、继电器、PCB |
| upstream_node | 上游节点，可能是材料、工艺、设备、公司、行业 |
| component_upstream_edge | 品类到上游节点的依赖关系 |
| mpn_material_profile | 单个型号的材料暴露画像 |
| process_dependency | 工艺和设备依赖 |
| company_dependency | 原厂、晶圆厂、封测厂、材料商关系 |
| market_signal | 行情、新闻、公告、涨价函、产能事件 |
| risk_evidence_chain | 风险依据链 |

### 9.2 关系类型

| 关系 | 示例 |
|---|---|
| CONTAINS_MATERIAL | 铝电解电容 → 阳极铝箔 |
| DERIVED_FROM | 阳极铝箔 → 高纯铝 |
| USES_PROCESS | PCB → 电镀 |
| REQUIRES_EQUIPMENT | 晶圆制造 → 光刻机 |
| MADE_BY | MCU → 原厂 |
| FOUNDRY_BY | 芯片 → 晶圆厂 |
| OSAT_BY | 芯片 → 封测厂 |
| EXPOSED_TO | 电源芯片 → 汽车电子需求 |
| AFFECTED_BY | 继电器 → 银价上涨事件 |
| PROPAGATES_TO | 银价上涨 → 继电器涨价风险 |

### 9.3 表结构草案

```sql
CREATE TABLE upstream_nodes (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    node_type VARCHAR(32) NOT NULL,      -- material/process/equipment/company/industry
    name VARCHAR(128) NOT NULL,
    normalized_name VARCHAR(128),
    parent_id INTEGER,
    description TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE component_upstream_edges (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    component_category VARCHAR(64) NOT NULL,
    upstream_node_id INTEGER NOT NULL,
    relation_type VARCHAR(32) NOT NULL,
    exposure_level VARCHAR(16) DEFAULT 'medium',  -- high/medium/low
    cost_weight_estimate FLOAT,
    confidence FLOAT DEFAULT 60,
    evidence_source TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP

CREATE TABLE mpn_material_profiles (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    mpn VARCHAR(128) NOT NULL,
    manufacturer VARCHAR(128),
    component_category VARCHAR(64),
    package_type VARCHAR(64),
    material_profile_json TEXT,
    process_profile_json TEXT,
    company_profile_json TEXT,
    confidence FLOAT DEFAULT 60,
    evidence_json TEXT,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE market_signals (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    signal_type VARCHAR(64) NOT NULL,    -- material_price/process_capacity/company/industry_order
    target_node_id INTEGER,
    target_name VARCHAR(128),
    title VARCHAR(256),
    signal_value FLOAT,
    unit VARCHAR(32),
    change_pct FLOAT,
    time_window VARCHAR(32),
    source_type VARCHAR(64),
    source_url TEXT,
    confidence FLOAT DEFAULT 60,
    raw_text TEXT,
    detected_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE risk_evidence_chains (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    bom_item_id INTEGER,
    mpn VARCHAR(128),
    risk_type VARCHAR(64),
    risk_level VARCHAR(16),
    risk_score FLOAT,
    chain_json TEXT NOT NULL,
    ai_judgement TEXT,
    confidence FLOAT DEFAULT 60,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
```

## 11. 落地阶段

### 阶段一：模板网络先行

先建立 20–30 个高频 BOM 品类的标准上游模板，不追求每个型号完全精准。重点覆盖：

- MCU、模拟芯片、数字芯片、电源芯片、MOSFET、IGBT、功率模块。
- PCB、连接器、继电器、开关、端子。
- MLCC、铝电解、薄膜电容、安规电容、压敏、热敏。
- 电阻、采样电阻、电感、变压器、磁珠、共模电感。

阶段一即可支撑大多数 PCBA 的上游风险提示。

### 阶段二：规格书增强

对高风险、高用量、高金额、替代困难的物料自动抓取规格书，抽取材料和工艺线索。优先处理：

- 继电器触点材料。
- 连接器镀层和端子材料。
- 铝电解电容容量、电压、尺寸和系列。
- PCB板层数、铜厚、板材等级。
- 功率模块封装、基板和键合材料。
- 芯片封装、产地、PCN/PDN、封测线索。

### 阶段三：半导体制造归属链

为重点芯片建立原厂、产品线、工艺节点、晶圆尺寸、晶圆厂、封测厂和下游行业映射。公开资料不足时，使用“推断 + 置信度”标注。

例如：

```text
某电源管理IC
→ 原厂：A公司
→ 工艺：BCD / 成熟制程，置信度 65
→ 晶圆：8寸，置信度 60
→ 风险：8寸产能紧张 + 汽车/工业电源需求上升
→ 影响：交期拉长风险中高
```

### 阶段四：企业私有知识沉淀

每次供应商确认、用户修正、采购反馈、替代料验证都写回知识库。系统越用越了解企业自己的物料结构、供应商偏好和真实风险。

## 12. 风险等级计算

v3.0 的最终风险分由六部分组成：

| 维度 | 权重 | 说明 |
|---|---:|---|
| 器件本体风险 | 25% | 库存、交期、生命周期、分销商价格 |
| 上游材料风险 | 20% | 铜、银、铝、硅片、树脂、玻纤、封装材料等 |
| 工艺/设备产能风险 | 15% | 晶圆、封测、PCB、烧结、电镀、绕线等瓶颈 |
| 公司/供应链实体风险 | 15% | 原厂、晶圆厂、封测厂、材料商、供应商经营风险 |
| 行业订单冲击 | 10% | 汽车、光伏、储能、AI服务器等需求挤占 |
| BOM影响程度 | 15% | 用量、金额、替代难度、项目数量、生产计划 |

```text
综合风险分 = 本体风险×0.25
          + 材料风险×0.20
          + 工艺产能风险×0.15
          + 公司实体风险×0.15
          + 行业冲击×0.10
          + BOM影响×0.15
```

等级建议：

| 分数 | 等级 | 含义 |
|---:|---|---|
| 80–100 | 红色 | 已有明确事件或多条高置信度路径指向供应/涨价风险 |
| 60–79 | 橙色 | 上游风险强，可能在 1–2 个月传导到采购 |
| 40–59 | 黄色 | 需要关注，建议扩展替代料或询价确认 |
| 20–39 | 绿色 | 有轻微信号，暂不影响采购动作 |
| 0–19 | 灰色 | 信息不足或未发现有效风险 |

## 15. 系统最终形态

v3.0 完成后，系统不再只是“BOM查库存/查价格”的工具，而是一个电子供应链风险推理系统。它能把供应商涨价函、原厂 PCN、材料行情、晶圆产能、封测排产、行业订单和企业自己的历史 BOM 串起来，形成能追溯、能解释、能量化的预警依据链。

用户看到的不是一句“此物料有风险”，而是：

```text
为什么有风险 → 风险从哪个上游节点传来 → 影响哪些物料 → 影响哪些PCBA和项目 → 有多紧急 → 该怎么处理
```

这就是 BOM 级风险预警从“被动查询”升级为“主动供应链风险雷达”的关键。
