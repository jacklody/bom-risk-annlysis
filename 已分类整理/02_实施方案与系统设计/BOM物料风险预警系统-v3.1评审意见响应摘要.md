# BOM物料风险预警系统 v3.1 评审意见响应摘要

> 日期：2026-06-25  
> 对应文件：《BOM物料风险预警系统：优化版系统设计方案 v3.1》

## 1. 总体采纳结论

评审意见已整体采纳。v3.1 不再把目标放在“尽可能完整地覆盖全部上游链条”，而是把系统可信度放在首位：每条传导链都要有可靠性等级、数据可获取性、转嫁率、滞后时间和预测验证结果。系统会区分“明确风险”“趋势关注”“弱关联提示”和“信息不足”，避免给出看似精确但缺乏依据的风险分。

## 2. 逐项响应

| 评审意见 | 采纳方式 | v3.1 对应章节 |
|---|---|---|
| 物料级预警置信度缺乏校准机制 | 增加预测验证闭环，记录每次预警并到期验证，用命中率反向修正模型 | 第13章 |
| 上游行情数据存在大量不可获取盲区 | 增加数据可获取性 A/B/C/D/E 分级，不再假设所有材料都有精确行情 | 第8章 |
| 材料涨价不等于器件涨价 | 增加转嫁率与滞后时间模型，材料传导必须乘以品类转嫁系数 | 第6章 |
| 缺少供需格局建模 | 增加供需平衡模型，用库存、交期、价格快照、替代料和行业需求评分 | 第7章 |
| IC类材料传导弱，强行评分会误导 | 将品类拆成成本驱动型、供需驱动型、混合驱动型；IC以供需和产能为主 | 第4章、第12章 |
| 缺少合同锁价和库存缓冲 | 增加缓冲因子模型，LTA、安全库存、替代料会降低短期紧急程度 | 第10章 |
| 缺少贸易政策风险 | 增加关税、出口管制、制裁清单、汇率和物流限制 | 第11章 |
| 缺少“信息不足”状态 | 增加信息不足输出，缺关键数据时不强行给绿色或橙色 | 第9章 |
| 固定权重不适合所有品类 | 重构为成本驱动、供需驱动、混合驱动三套评分模型 | 第12章 |
| MVP范围过大 | 调整为先做 PCB、铝电解、继电器、连接器、功率电感/变压器五类高可靠品类 | 第16章 |
| 半导体制造归属链公开数据不足 | MVP阶段暂缓全量IC制造归属链，只保留供需和交期信号 | 第16章、第18章 |

## 3. v3.1 的核心产品变化

### 3.1 从固定评分变为分品类评分

v3.0 使用统一六维权重。v3.1 改为三套模型：

```text
成本驱动型：PCB、继电器、连接器、电感、变压器、铝电解
供需驱动型：MCU、模拟芯片、数字芯片、电源芯片、普通IC
混合驱动型：MLCC、薄膜电容、功率模块、压敏、热敏、安规电容
```

这样可以避免“硅片上涨导致 MCU 橙色风险”这类误判。

### 3.2 从材料价格判断变为传导链判断

系统不再直接把材料涨幅映射为器件风险，而是计算：

```text
材料涨幅 × 材料暴露 × 品类转嫁率 × 传导可靠性 × 证据强度 × 时间窗口
```

铜价对 PCB、电感、继电器的传导权重较高；光刻胶、塑封料对普通 IC 的传导权重较低。

### 3.3 从“必须给结论”变为“允许说信息不足”

v3.1 增加信息不足状态。系统不能识别品类、缺规格书、缺供应链信息或上游数据不可得时，会明确提示缺少哪些信息，而不是输出一个低置信度的绿色结论。

### 3.4 从一次性预警变为可验证预警

每条预警都会记录预测对象、风险类型、预期时间窗口、依据链和模型版本。到期后系统会比对实际价格、交期、库存和生命周期变化，判断预警是否命中。

## 4. MVP落地变化

v3.1 建议 MVP 只覆盖高可靠链条：

| 范围 | 内容 |
|---|---|
| 品类 | PCB、铝电解电容、继电器、连接器、功率电感/变压器 |
| 材料 | 铜、银、铝 |
| 数据源 | 公开金属行情、供应商涨价函、分销商价格/交期、历史采购价 |
| 模型 | 成本驱动型评分、传导链可靠性、转嫁率、滞后时间、缓冲因子 |
| 验证 | 记录预警并在1–6个月窗口内验证价格或交期变化 |

暂缓内容包括全量 IC 制造归属链、全材料行情、高级图谱可视化和全品类覆盖。

## 5. 修订后的系统价值

v3.1 的价值不是预测所有风险，而是让每一次风险提示都有边界、有证据、有置信度、有验证结果。

```text
高证据链条 → 明确预警
趋势存在但证据不足 → 标注关注
传导链弱 → 降权展示
关键数据缺失 → 信息不足
预警到期 → 自动验证并校准模型
```

这版方案更适合真实开发和企业采购场景，也更能保护系统长期可信度。
