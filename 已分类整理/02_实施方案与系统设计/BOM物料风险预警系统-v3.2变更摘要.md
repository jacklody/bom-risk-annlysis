# BOM物料风险预警系统 v3.2 变更摘要

> 日期：2026-06-25  
> 对应文件：《BOM物料风险预警系统：双轨情报与自进化方案 v3.2》

## 1. 本次更新吸收的输入

本次 v3.2 基于三类输入调整：

1. 原始调研报告中的平台经验、第三方工具能力、免费 API、自建系统路线和国内供应链实践。
2. 双轨策略与自进化机制建议中的“材料传导 + 供需信号”双轨模型、人工触发、同行联动和预测验证闭环。
3. 用户补充的现实行情判断：高容 MLCC 已出现涨价和缺货，不能再只作为普通 MLCC 的弱观察项。

## 2. 相对 v3.1 的主要变化

| 变化项 | v3.1 | v3.2 |
|---|---|---|
| 系统定位 | 可解释 BOM 风险雷达 | 企业级电子供应链情报系统 |
| 核心模型 | 成本驱动、供需驱动、混合驱动 | 材料传导轨 + 供需信号轨双轨并行 |
| 商业平台经验 | 借鉴评分和验证 | 系统化吸收 SiliconExpert、Z2Data、Octopart、Altium、云汉、华秋等能力 |
| 情报来源 | API、涨价函、公开行情 | 增加微信公众号、行业媒体、研究机构、财报、采购反馈、人工触发 |
| 公众号处理 | 未成体系 | 建立来源分层、可信度、字段完整度、多源验证、历史命中率 |
| 高容 MLCC | 混合驱动，黄色关注 | 单独升为重点风险项，纳入 MVP |
| 人工触发 | 预测验证的一部分 | 正式成为系统学习入口，可触发联动规则和后续验证 |
| 同行联动 | 初步提出 | 形成品牌/品类/替代料/配套物料联动模型 |
| MVP范围 | 5类材料传导高可靠品类 | 增加 MCU、PMIC、功率器件、分立器件、高容 MLCC |

## 3. 平台经验如何落地

| 平台 | 借鉴点 | 自建系统转化 |
|---|---|---|

## 4. 高容 MLCC 的处理变化

高容 MLCC 从普通 MLCC 中拆出来，作为独立风险对象处理。

```text
普通MLCC：按混合驱动模型观察
高容MLCC：按“供需紧张 + 行情事实 + 材料工艺约束”重点预警
```

识别字段包括容值、尺寸、介质、电压、应用和品牌。系统重点监测：

- 10uF、22uF、47uF、100uF 等高容规格。
- 0402、0603、0805、1206 等常用尺寸。
- X5R、X7R、X8R 等介质。
- AI服务器电源、汽车、工业电源、储能、电源模块等应用。
- 村田、TDK、太阳诱电、三星电机、国巨、华新科、风华高科、三环等品牌。

## 5. 微信公众号和行业媒体的处理规则

v3.2 不把公众号文章直接作为结论，而是纳入情报池：

```text
公众号/媒体文章
→ 来源分层
→ 抽取品牌、品类、涨幅、缺货、交期、原因
→ 判断是否有原始出处
→ 与分销商价格、库存、涨价函、采购反馈交叉验证
→ 进入确认事件 / 高可信趋势 / 早期信号 / 市场传闻 / 噪声
```

来源分层：

| 层级 | 类型 | 处理 |
|---|---|---|
| A | 原厂、政府、协会、上市公司公告 | 强证据 |
| B | 研究机构、权威行业媒体 | 中高证据 |
| C | 垂直产业公众号 | 观察或待验证 |
| D | 市场渠道自媒体 | 辅助信号，需降权 |
| E | 无法追溯来源 | 噪声记录 |

## 6. MVP调整

v3.2 的 MVP 改为双轨验证。

### 材料传导轨

- PCB
- 铝电解
- 继电器
- 连接器
- 电感/变压器
- 铜、银、铝行情
- 供应商涨价函

### 供需信号轨

- MCU
- PMIC/电源芯片
- 功率器件
- 分立器件
- 高容 MLCC
- 同行联动
- 交期库存变化
- 人工触发行情

## 7. 新增数据表

v3.2 建议新增四类表：

| 表 | 作用 |
|---|---|
| `intelligence_sources` | 管理行业媒体、公众号、原厂、研究机构、人工来源可信度 |
| `market_intelligence_events` | 存储涨价、缺货、交期、产能、需求、政策等行情事件 |
| `manual_alert_events` | 存储人工触发的风险事件 |
| `linkage_rules` | 存储同行联动、配套物料联动、替代料挤占规则 |
| `mlcc_risk_profiles` | 存储高容 MLCC 的规格画像和风险信号 |

## 8. 最终结论

v3.2 把系统从“物料风险评分工具”推进到“电子供应链情报系统”。它吸收商业平台的成熟思路，但不依赖付费平台才能启动；它把公众号和行业媒体纳入情报来源，但通过可信度和交叉验证防止误报；它把高容 MLCC 这类已经涨价缺货的事实风险纳入 MVP，而不是继续等待材料模型验证。

这版最重要的变化是：系统允许人工把真实行情喂进去，并通过后续验证让系统学会。
