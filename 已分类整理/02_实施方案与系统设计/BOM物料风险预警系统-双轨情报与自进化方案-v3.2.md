# BOM物料风险预警系统：双轨情报与自进化方案 v3.2

> 更新日期：2026-06-25  
> 修订依据：原始调研报告、双轨策略与自进化机制建议、v3.1 优化版系统设计方案  
> 核心升级：吸收商业平台方法论，加入行业媒体/微信公众号情报池，把高容 MLCC 等“已涨价且缺货”的事实风险纳入 MVP，并建立人工触发、自进化和多源甄别机制

## 1. 这次修订的核心判断

v3.1 已经把系统从“单一材料传导模型”改成“分品类、分可靠性、可验证”的风险雷达。v3.2 进一步明确：系统不能只靠 API 和公开行情，也要主动吸收商业平台的成熟经验、行业媒体和微信公众号里的行情情报、采购端收到的涨价函、缺货反馈、供应商报价变化和人工经验判断。

商业平台的数据和算法未必都能免费接入，但它们的产品思想可以借鉴：

- **SiliconExpert** 的核心启发是“物料全生命周期健康度”：从设计选型开始就监控生命周期、合规、替代料和供应链风险。其官网强调 BOM 风险、生命周期预测、短缺和市场变化预警能力。<sup><a href="#cite-1">[1]</a></sup>
- **Z2Data** 的核心启发是“从 MPN 扩展到供应商、制造基地、Sub-tier 和全球事件”：它把 BOM、PCN、供应商、制造地点、实时市场事件和分层供应链风险放在一个平台里。<sup><a href="#cite-2">[2]</a></sup>
- **Octopart** 的核心启发是“多分销商聚合比单点查询更可靠”：它聚合授权分销商、制造商和技术规格，提供价格、库存、可用性和技术信息的统一视图。<sup><a href="#cite-3">[3]</a></sup>
- **Altium 365** 的核心启发是“BOM 管理要嵌入研发流程”：它把供应链数据接入设计、库管理和制造协作，而不是等 BOM 定型后才处理风险。<sup><a href="#cite-4">[4]</a></sup>
- **TrendForce** 的核心启发是“产业趋势与价格趋势可作为先导信号”：其定位覆盖行业分析、价格趋势和竞争情报，并已把 MLCC、硅电容、AI 电源完整性等作为行业洞察主题。<sup><a href="#cite-5">[5]</a></sup>

v3.2 的系统定位调整为：

```text
BOM风险预警 = 本体数据 + 材料传导 + 供需信号 + 行业情报 + 人工触发 + 自进化验证
```

系统既要能自动发现风险，也要允许采购、工程、供应链人员把“已经知道的行情事实”喂给系统，让系统用这些事实反向学习。

## 2. v3.2 相对 v3.1 的关键变化

| 方向 | v3.1 | v3.2 |
|---|---|---|
| 平台经验 | 借鉴风险评分、预测验证 | 进一步吸收 SiliconExpert、Z2Data、Octopart、Altium、云汉、华秋等平台思路 |
| 数据接入 | API、涨价函、公开行情、交期库存 | 增加行业媒体、微信公众号、企业公告、财报、采购反馈、人工触发情报 |
| 模型架构 | 成本驱动、供需驱动、混合驱动 | 明确“双轨策略”：材料传导轨 + 供需信号轨并行运行 |
| 自进化 | 预测验证闭环 | 增加人工触发、规则注入、同行联动、联动系数自校准 |
| MVP品类 | PCB、铝电解、继电器、连接器、电感/变压器 | 增加 MCU、PMIC、功率器件、分立器件、高容 MLCC 等已发生行情风险的品类 |
| MLCC | 混合驱动，偏谨慎关注 | 高容 MLCC 单独升为重点风险项，按“材料 + 供需 + 涨价缺货事实”处理 |
| 公众号情报 | 未系统化 | 建立公众号/行业媒体情报池和真伪甄别机制 |
| 商业平台不可接入 | 暂未明确处理 | 不可免费接入时借鉴指标、页面逻辑、风险因子和数据结构 |

## 3. 商业平台经验如何转化为自建系统能力

### 3.1 SiliconExpert：借鉴“BOM健康度”和生命周期风险

SiliconExpert 的价值不只是数据库，而是把物料选型、生命周期、合规、供应链风险放进统一健康度框架。自建系统可借鉴以下能力，不必一开始购买全量数据。

| 可借鉴思路 | 自建实现 |
|---|---|
| 物料健康度评分 | 为每颗 MPN 建立 `part_health_score`，综合生命周期、库存、供应商数、替代料、价格波动、信息充分度 |
| 预测性 EOL | 如果库存长期下降、分销商数量减少、原厂新品替代出现、PCN频繁，则提升“潜在停产”风险 |
| 替代推荐 | 先基于封装、参数、品牌、公司 AVL 做规则推荐，再由人工确认 |
| 合规与材料文档 | 记录 RoHS、REACH、冲突矿产、材料声明文件状态，作为供应风险辅助字段 |
| 生命周期设计前置 | 新 BOM 审查时，NRND/EOL/单一来源直接拦截或强提示 |

### 3.2 Z2Data：借鉴“多层供应链和事件监控”

Z2Data 的强项是把组件、供应商、制造基地、PCN、Sub-tier、全球事件和市场警报串起来。自建系统可先实现轻量版。

| 可借鉴思路 | 自建实现 |
|---|---|
| Tier1-3供应链可视化 | 不追求完整商业图谱，先建立“品牌/原厂 → 代理/供应商 → 可能制造地/封测地/材料节点”的粗粒度关系 |
| 制造基地风险 | 对已知产地、晶圆厂、封测厂、PCB厂所在地区添加地缘、自然灾害、停电、疫情、政策风险 |
| 供应商实体风险 | 对接企查查、天眼查、供应商黑名单、合作历史、账期异常、诉讼经营异常 |
| PCN工作流 | PCN/PDN/EOL 进入系统后自动匹配 BOM、分派确认、跟踪替代方案和 LTB |
| 实时事件监控 | 将行业新闻、政策、自然灾害、公司公告抽取为事件，再映射到供应商/品类/BOM |

### 3.3 Octopart / Findchips：借鉴“多分销商聚合视图”

Octopart 的价值在于把多家授权分销商、制造商和技术规格统一查询。自建系统应避免只依赖一个分销商。

| 可借鉴思路 | 自建实现 |
|---|---|
| 多源库存聚合 | LCSC、Mouser、Digi-Key、云汉、华秋、得捷、贸泽、半导小芯、芯查查等并行查询 |
| 中位价/离散度 | 对多渠道报价计算中位价、最低价、最高价、离散度，识别炒货或异常报价 |
| 授权渠道优先 | 授权分销商权重大于现货市场，现货市场仅作为短缺和价格异动参考 |
| 技术规格补全 | 从产品页和 datasheet 补充封装、参数、生命周期、替代料候选 |
| 查询缓存 | 建立价格/库存快照，形成趋势而不是只看实时点值 |

### 3.4 Altium 365：借鉴“研发阶段前置管控”

Altium 365 把供应链数据接入设计流程，核心启发是风险不能等到采购阶段才处理。

| 可借鉴思路 | 自建实现 |
|---|---|
| 设计库健康度 | 对公司常用物料库定期巡检，提前标出不推荐新设计的物料 |
| 新 BOM 审查 | 上传新 BOM 时检查标准化、库存、交期、生命周期、替代料、国产替代、上游风险 |
| 版本化追踪 | 记录每版 BOM 的风险变化，看风险是由设计变更还是市场变化引起 |
| 制造协同 | 把 PCB、PCBA、供应商报价和制造风险接入同一项目视图 |
| 设计阶段替代 | 在工程阶段给出 pin-to-pin、同封装、同参数、国产替代候选 |

### 3.5 国内平台经验：云汉、华秋、立创、世强

第一附件中的国内平台经验要纳入产品设计，重点不是简单复制平台，而是把能力拆成系统模块。

| 平台经验 | 可借鉴能力 | 系统模块 |
|---|---|---|
| 云汉芯城 | 标准化 SPU、替代关系、国产替代、BOM解析 | 型号归一化、企业SPU库、替代料库、国产替代库 |
| 华秋电子 | DFM + BOM + PCBA制造一体化 | PCB/PCBA制造风险、PCB工艺和交期评估 |
| 立创商城 | 免费库存、价格、数据手册、基础物料标记 | 免费 API 数据源、基础物料优选标识 |
| 世强硬创 | 国产器件覆盖、代理资源 | 国产替代候选、品牌/代理商信息补充 |
| 华强北现货市场 | 价格异动和缺货热度 | 辅助信号，不作为单独强证据 |

## 4. 双轨预警策略

v3.2 正式把“双轨策略”作为核心架构。材料传导轨负责“原材料涨价导致器件成本压力”，供需信号轨负责“需求爆发、产能迁移、品牌联动、交期拉长、库存下降导致涨价缺货”。

```text
第一轨：材料传导链
大宗商品/材料 → 二级组份 → 器件成本 → 供应商报价

第二轨：供需信号链
终端需求/产能/同行涨价/交期库存 → 品类供需失衡 → 器件涨价缺货

融合引擎
按品类动态权重 + 证据强度 + 传导可靠性 + 缓冲因子 + BOM影响
```

### 4.1 第一轨：材料传导链

适用于材料成本占比较高的品类。

| 传导链 | 适用品类 | 可靠性 | 转嫁率 | 滞后时间 |
|---|---|---|---:|---|
| 铜 → 铜箔/覆铜板 → PCB | PCB | 高 | 60%–80% | 1–3个月 |
| 铜 → 漆包线 → 电感/变压器 | 电感、变压器 | 高 | 50%–70% | 2–4个月 |
| 银 → AgSnO2/AgNi触点 → 继电器 | 继电器 | 高 | 30%–50% | 2–4个月 |
| 铝 → 电极箔 → 铝电解电容 | 铝电解 | 中高 | 40%–60% | 3–6个月 |
| 铜/金/锡/镍 → 端子镀层 → 连接器 | 连接器 | 中高 | 20%–40% | 3–6个月 |
| 环氧树脂/玻纤布 → 覆铜板 → PCB | PCB | 中 | 视供应商报价 | 2–4个月 |

### 4.2 第二轨：供需信号链

适用于 IC、功率器件、存储、高容 MLCC、部分分立器件等供需驱动或混合驱动品类。

| 信号 | 判断逻辑 | 触发风险 |
|---|---|---|
| 交期拉长 | 分销商/供应商交期连续上升，或从正常交期变为 12 周以上 | 缺货、排产紧张 |
| 多渠道库存下降 | 多家分销商库存同步下降，渠道数减少 | 供应收缩 |
| 同行联动涨价 | 同品类头部品牌或竞品已发涨价函 | 品类级涨价风险 |
| 终端需求爆发 | AI服务器、汽车、光伏、储能、工业控制需求上升 | 产能挤占 |
| 产能迁移 | 产线向 AI、汽车、高毛利品转移，消费/通用品供给减少 | 结构性缺货 |
| 原厂策略变化 | 控单、延交、缩短报价有效期、取消折扣 | 涨价和供应不确定 |
| 渠道炒货 | 现货市场异常跳价、捂货惜售 | 二级市场风险，需降权验证 |

## 5. 高容 MLCC 升级为重点风险项

用户明确指出高容 MLCC 已经涨价缺货，这类物料不能再只作为“理论混合驱动”谨慎观察。v3.2 将高容 MLCC 单独纳入 MVP 风险评估。

高容 MLCC 同时具备三类信号：

1. 材料属性：钛酸钡、镍、铜、银钯、电极浆料、陶瓷粉体、烧结和电镀工艺。
2. 供需属性：高容值、小尺寸、高可靠、车规、AI服务器和高性能电源需求上升。
3. 行情事实：市场已出现涨价、缺货、控单、交期拉长或渠道跳价时，应直接进入风险评估，而不是等材料行情验证。

### 5.1 高容 MLCC 风险模型

```text
高容MLCC风险分 = 本体信号 × 0.20
              + 供需紧张 × 0.25
              + 同行联动 × 0.15
              + 行情事实 × 0.20
              + 材料与工艺 × 0.10
              + BOM影响 × 0.10
              - 缓冲因子
```

其中“行情事实”包括：

| 事实信号 | 证据等级 | 处理方式 |
|---|---|---|
| 原厂涨价函 | 强证据 | 直接触发橙色/红色候选 |
| 授权代理涨价通知 | 强证据 | 匹配同系列和同规格 BOM |
| 多分销商同步涨价 | 强证据 | 与库存下降联动判断 |
| 交期从正常变为 12 周以上 | 强证据 | 触发缺货风险 |
| 高容规格现货市场跳价 | 中证据 | 需与授权渠道、采购反馈交叉验证 |
| 微信公众号/媒体报道“涨价缺货” | 中/弱证据 | 至少两类来源验证后触发 |

### 5.2 高容 MLCC 识别规则

系统在 BOM 解析时应识别高容 MLCC，而不是把所有 MLCC 混在一起。

| 识别维度 | 示例 |
|---|---|
| 容值 | 10uF、22uF、47uF、100uF 及以上，结合电压和尺寸判断 |
| 尺寸 | 0402、0603、0805、1206，不同尺寸风险不同 |
| 介质 | X5R、X7R、X8R、C0G/NP0 |
| 电压 | 6.3V、10V、16V、25V、50V、100V |
| 应用 | AI服务器电源、汽车、工业电源、储能、电源模块 |
| 品牌 | 村田、TDK、太阳诱电、三星电机、国巨、华新科、风华高科、三环等 |

### 5.3 高容 MLCC 输出样式

```text
物料：22uF 25V X7R 0805 MLCC
风险等级：橙色
驱动类型：混合驱动，供需优先
已确认事实：高容 MLCC 市场存在涨价/缺货信号
主要依据：同类规格渠道库存下降 + 高容规格报价上升 + AI服务器/高功率电源需求上升
材料辅助依据：陶瓷粉体、电极材料、烧结产能对供应有约束
系统判断：该规格不应按普通 MLCC 低风险处理，建议提前锁价、扩展多品牌替代、核查库存覆盖周期。
```

## 6. 行业媒体和微信公众号情报池

微信公众号和行业媒体确实能提供大量半导体行情信息，但可信度差异很大。v3.2 不把公众号文章直接当结论，而是把它们作为“早期信号源”，经过来源分层、内容抽取、交叉验证后再进入风险评估。

### 6.1 推荐纳入监测的信息源类型

| 层级 | 类型 | 示例 | 适合提取的信息 | 默认可信度 |
|---|---|---|---|---:|
| A | 官方/原厂/上市公司 | 原厂官网、投资者关系、PCN/PDN、财报、交易所公告 | 涨价、停产、产能、产品线变化 | 0.95 |
| A | 政府/协会/标准机构 | 工信部、海关、SIA、SEMI、JEDEC | 政策、产业数据、标准、出口限制 | 0.90 |
| B | 专业研究机构 | TrendForce、Omdia、IDC、Counterpoint、Yole、集邦咨询 | 价格趋势、供需、行业周期 | 0.80 |
| B | 行业专业媒体 | 集微网、半导体行业观察、芯东西、电子工程专辑、国际电子商情、电子发烧友、与非网、芯智讯 | 行情、公司动态、产业链事件 | 0.65–0.75 |
| C | 垂直产业公众号 | 艾邦半导体网、半导体产业纵横、芯榜、芯师爷、芯片揭秘、芯通社等 | 品类涨价、渠道动向、供应链传闻 | 0.45–0.65 |
| D | 市场/渠道自媒体 | 华强北现货号、贸易商报价号、二级市场行情号 | 缺货、跳价、捂货、炒货 | 0.25–0.45 |
| E | 未知来源搬运 | 无原始出处、标题党、无法追溯 | 仅作噪声记录 | 0.10–0.20 |

说明：以上公众号/媒体应作为“候选监测池”。实际系统需维护账号白名单、黑名单和历史命中率。某个来源如果多次被验证准确，可信度上调；多次夸大或误报，可信度下降。

### 6.2 公众号情报甄别规则

系统从公众号/媒体抽取行情信息后，先做四步判断。

```text
文章来源识别
→ 是否有原始出处：原厂公告/涨价函/财报/研究机构报告/采访
→ 是否有可核验字段：品牌、品类、涨幅、时间、受影响型号、原因
→ 是否被多源重复验证：至少一个强源或两个中等来源
→ 是否能映射到BOM：品牌/品类/规格/MPN是否命中企业BOM
```

| 判断项 | 加分 | 扣分 |
|---|---:|---:|
| 引用了原厂公告、财报、涨价函 | +30 |  |
| 有具体品牌、品类、涨幅、生效日期 | +25 |  |
| 多个独立来源报道同一事件 | +20 |  |
| 与分销商价格/库存趋势一致 | +20 |  |
| 只有“据传”“市场消息” |  | -20 |
| 无原始出处、无具体型号 |  | -25 |
| 标题夸张、正文缺少数据 |  | -20 |
| 与授权渠道数据矛盾 |  | -30 |

### 6.3 公众号情报进入风险评估的等级

| 情报等级 | 条件 | 系统动作 |
|---|---|---|
| 确认事件 | 原厂/代理/财报/多源强验证 | 直接进入风险事件，匹配 BOM |
| 高可信趋势 | 专业媒体 + 研究机构 + 分销数据一致 | 进入橙色候选，触发人工复核或自动预警 |
| 早期信号 | 单个专业媒体或多个弱源一致 | 进入观察池，提高相关品类监测频率 |
| 市场传闻 | 渠道自媒体、现货市场口径 | 只记录，不直接触发高风险 |
| 噪声 | 无法追溯、与事实矛盾 | 不进入评分，保留原文备查 |

## 7. 人工触发与自进化机制

v3.2 将人工触发作为正式功能，而不是兜底操作。采购或工程人员已经知道“兆易 MCU 涨价缺货”“MPS/圣邦微电源类涨价”“英飞凌功率器件涨价”“高容 MLCC 缺货涨价”时，应能手动录入系统，系统立刻反推受影响 BOM 并沉淀为规则。

### 7.1 人工触发字段

| 字段 | 示例 |
|---|---|
| 品类 | MCU、PMIC、功率器件、分立器件、高容 MLCC |
| 品牌/供应商 | 兆易创新、MPS、圣邦微、英飞凌、国巨、村田等 |
| 信号类型 | 涨价、缺货、交期延长、控单、产能紧张、同行联动 |
| 涨幅 | 10%、15%、20%，或区间 |
| 缺货程度 | 轻微、明显、严重、全渠道无货 |
| 生效日期 | 供应商通知日期或预计生效日期 |
| 信息来源 | 涨价函、供应商口头通知、行业媒体、公众号、采购反馈 |
| 关联品类 | 同品类、配套 PMIC、配套存储、上游材料、替代料 |
| 置信度 | 人工给定或系统计算 |

### 7.2 人工触发后的自动动作

```text
人工录入行情事件
→ 结构化为 risk_event
→ 匹配历史BOM、新BOM、AVL和替代料库
→ 识别同品类和关联品类
→ 触发同行联动预警
→ 生成验证任务
→ 写入规则权重表
→ 后续自动抓取价格/库存/交期验证是否命中
```

### 7.3 同行联动模型

```text
品牌A涨价/缺货
→ 同品类品牌B/C/D风险上升
→ 同应用链配套物料风险上升
→ 替代料需求上升，替代料也可能被挤占
```

| 关系 | 联动系数初值 | 示例 |
|---|---:|---|
| 完全同品类竞品 | 0.8–1.0 | 兆易 MCU → 中微半导/国民技术 MCU |
| 同品类不同定位 | 0.4–0.7 | 工业 MCU → 消费 MCU |
| 配套物料 | 0.3–0.5 | MCU → PMIC、存储、晶振 |
| 替代料挤占 | 0.5–0.8 | 某品牌缺货 → pin-to-pin 替代品牌需求上升 |
| 同上游产能 | 0.4–0.6 | 同为 8寸成熟制程的模拟/电源芯片 |

联动系数不是固定值。系统通过预测验证不断调整：命中就上调，误报就下调。

## 8. v3.2 风险评分模型

v3.2 保留 v3.1 的三类模型，但加入“行情事实”“同行联动”“情报可信度”和“人工触发权重”。

### 8.1 成本驱动型

适用于 PCB、铝电解、继电器、连接器、电感、变压器、线束。

```text
风险分 = 本体信号 × 0.18
      + 材料传导 × 0.28
      + 行情事实 × 0.16
      + 供需平衡 × 0.12
      + 工艺产能 × 0.08
      + 贸易政策 × 0.08
      + BOM影响 × 0.10
      - 缓冲因子
```

### 8.2 供需驱动型

适用于 MCU、PMIC、电源 IC、模拟 IC、数字 IC、存储、部分功率器件。

```text
风险分 = 本体信号 × 0.20
      + 供需平衡 × 0.24
      + 同行联动 × 0.16
      + 行情事实 × 0.16
      + 终端需求冲击 × 0.10
      + 工艺产能 × 0.06
      + 贸易政策 × 0.05
      + BOM影响 × 0.03
      - 缓冲因子
```

说明：IC 类材料传导仍然降权，除非有晶圆厂涨价、封测涨价、原厂涨价函或供应商报价确认。

### 8.3 混合驱动型

适用于高容 MLCC、薄膜电容、安规电容、功率模块、分立器件、部分压敏/热敏。

```text
风险分 = 本体信号 × 0.18
      + 供需平衡 × 0.20
      + 行情事实 × 0.20
      + 同行联动 × 0.12
      + 材料传导 × 0.12
      + 工艺产能 × 0.08
      + 终端需求冲击 × 0.05
      + BOM影响 × 0.05
      - 缓冲因子
```

### 8.4 情报可信度系数

所有来自行业媒体、公众号、渠道市场的信息都要乘以情报可信度系数。

```text
有效情报分 = 原始事件分 × 来源可信度 × 字段完整度 × 多源验证系数 × 历史命中率
```

| 来源类型 | 初始可信度 |
|---|---:|
| 原厂公告/涨价函/PCN/PDN | 0.95 |
| 授权代理通知/采购合同报价 | 0.90 |
| 研究机构报告 | 0.80 |
| 权威行业媒体 | 0.65–0.75 |
| 垂直公众号 | 0.45–0.65 |
| 渠道自媒体/现货市场 | 0.25–0.45 |
| 无法追溯来源 | 0.10–0.20 |

## 9. MVP 范围重新调整

v3.2 的 MVP 不应只做材料传导，因为当前真实行情已经显示 MCU、PMIC、功率器件、高容 MLCC、分立器件等正在发生涨价缺货。MVP 应验证双轨模型。

### 9.1 第一轨 MVP：材料传导

| 品类 | 风险来源 | 数据源 |
|---|---|---|
| PCB | 铜、覆铜板、玻纤布、树脂 | 铜价、PCB供应商报价、PCB厂交期 |
| 铝电解 | 铝、电极箔、电解液 | 铝价、供应商涨价函、库存交期 |
| 继电器 | 银触点、铜线圈 | 银价、铜价、规格书触点材料 |
| 连接器 | 铜合金、镀金/镀锡、塑胶 | 铜价、金锡镍、连接器供应商报价 |
| 电感/变压器 | 铜线、磁芯 | 铜价、磁芯供应商、交期 |

### 9.2 第二轨 MVP：供需信号

| 品类 | 已知风险 | 重点信号 |
|---|---|---|
| MCU | 部分品牌涨价缺货 | 交期、库存、同行联动、8寸产能、汽车/工业需求 |
| PMIC/电源芯片 | 部分品牌涨价 | AI服务器、电源模块需求、交期、供应商报价 |
| 功率器件 | 10%–20%涨价常见，新能源需求拉动 | IGBT/MOSFET/SiC供需、光伏/储能/汽车订单 |
| 分立器件 | 涨价函和晶圆代工涨价传导 | 同行联动、封测、晶圆代工、铜锡材料 |
| 高容 MLCC | 已涨价缺货 | 高容规格库存、交期、渠道价格、AI服务器/汽车需求 |

### 9.3 情报源 MVP

| 类型 | 先接入方式 |
|---|---|
| LCSC / Mouser / Digi-Key / 云汉 / 华秋 | API或半自动查询，形成库存/价格快照 |
| 原厂官网 / PCN / PDN | 手动导入 + 后续爬取/订阅 |
| 涨价函 / 供应商通知 | 上传文件，LLM结构化抽取 |
| 行业媒体/公众号 | 先建立人工录入和链接保存，后续再做自动采集 |
| 公众号情报池 | 先做来源白名单、可信度和多源验证，不直接自动高风险 |
| 人工触发 | 必须进入 MVP，作为系统学习入口 |

物料：某32位MCU

## 14. 系统最终形态

v3.2 后，系统不再只是“查 BOM 风险”，而是一个企业级电子供应链情报系统。它既吸收商业平台的方法论，也利用免费 API、公开行情、行业媒体、公众号、涨价函、采购反馈和人工经验，逐步形成企业自己的风险知识库。

关键原则是：

```text
能接 API 的，自动接入
不能接 API 的，借鉴指标和方法
能拿到原始证据的，结构化入库
只能看到媒体/公众号的，分层甄别后入观察池
人工已经知道的行情，立即录入并让系统学习
涨价缺货已成事实的品类，直接纳入 MVP 风险评估
```

这版设计把“已发生行情”与“可预测风险”放在同一套系统里处理。对 PCB、继电器、电感、铝电解等材料传导明确的品类，系统看上游材料；对 MCU、PMIC、功率器件、高容 MLCC 等供需驱动品类，系统看交期、库存、同行涨价、终端需求和人工情报。两条轨道并行，才能覆盖真实电子行业 BOM 风险。
