# 上游原材料价格追踪 — 完整实施方案

## 一、现状分析

### 1.1 已有的基础设施

当前系统已为原材料传导预留了数据管道，尚未接入真实价格数据：

| 模块 | 文件 | 已有内容 | 状态 |
|------|------|---------|------|
| 品类分类器 | `category_classifier.py` | 每个品类定义了 `upstream_materials` | 已就绪 |
| 传播规则 | `propagation_rules.py` | `MATERIAL_SIGNAL_WEIGHTS` 定义了材料信号权重 | 已就绪 |
| 上下文构建 | `risk_context_builder.py` | `_material_signals_for_category()` 从事件描述中提取材料信号 | **需替换** |
| 双轨引擎 | `dual_track_risk_engine.py` | material track 权重 0.25~0.70 | 已就绪 |
| 聚合结果 | `supply_data.py` | `AggregatedResult` 含 worst_case 视图 | 已就绪 |

### 1.2 当前瓶颈

材料信号来自事件文本描述，只能响应"已经写成文章"的波动，无法捕捉**实时价格变化**。铜价涨 8% 但在媒体发文之前系统毫无反应。

### 1.3 三大数据域

根据原材料特性，划分为三个独立数据域，各自有不同的数据源和采集策略：

| 域 | 涵盖材料 | 标杆数据源 | 数据频率 |
|----|---------|-----------|---------|
| **有色金属域** | 铜/铝/银/锡/镍/钽/钴 | metals-api.com (免费) | 日级 |
| **稀土 & 小金属域** | 氧化镨钕/氧化镝/碳酸钡/钛白粉/钽粉 | 稀土行业协会 / 亚洲金属网 | 日-周级 |
| **化工 & 非金属域** | 环氧树脂/电解液/玻纤布/聚丙烯/PET | 生意社 / 卓创资讯 | 周级 |

## 八、波动阈值与预警规则

### 8.1 价格波动触发规则（所有材料统一）

| 波动幅度 (30日) | 风险等级 | 系统行为 |
|----------------|---------|---------|
| 涨幅 5% ~ 10% | **YELLOW** | 物料轨加分 +10，Dashboard 提示 |
| 涨幅 10% ~ 20% | **ORANGE** | 物料轨加分 +20，生成 MarketEvent |
| 涨幅 ≥ 20% | **RED** | 物料轨加分 +35，直接告警推送 |
| 跌幅 ≥ 10% | **GREEN** | 物料轨加分 -15，提示采购窗口 |

### 8.2 传导公式

```
单品类材料风险分 = Σ( 材料_i_价格变动% × 传导系数_i ) × model_weight
```

- `传导系数 = 成本占比`（见第三章映射表）
- `model_weight` 在 `category_classifier.py` 中定义

示例 — MLCC 传导计算：
```
MLCC材料风险 = 
  TiO2 +12%  × 0.12 +
  BaCO3 +8%  × 0.10 +
  Dy₂O₃ -3% × 0.08 +
  Y₂O₃ +2%  × 0.05 +
  Ni   +15% × 0.15 +
  Cu   +10% × 0.08
= 1.44 + 0.80 - 0.24 + 0.10 + 2.25 + 0.80
= 5.15%

MLCC风险分 = 5.15 × 0.40 (model_weight) = 2.06
→ 低于 5% 阈值，不触发预警
```

### 8.3 稀土的特殊性

稀土价格波动比普通金属剧烈得多。氧化镝的历史年波动率经常超过 50%，所以稀土材料的阈值不变（5%/10%/20%），但**传导系数上调 1.6 倍**（稀土均价波动本身就大，0.08 → 实际用于比较时乘 1.6）：

```
# 稀土材料传导系数调整因子
RARE_EARTH_AMPLIFIER = 1.6
# 波动判定时不放大百分比（波动率本身已高），
# 但在传导计算中放大风险分。
adjusted_weight = base_weight * RARE_EARTH_AMPLIFIER
```
